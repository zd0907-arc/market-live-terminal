## 粤桂外部驱动修正

粤桂不能只按化工/硫酸基本面看。近期核心链条是：

```text
伊朗/中东紧张 -> 原油上涨 -> 硫磺/硫酸价格预期 -> 粤桂硫资源和业绩弹性 -> 股价冲高
```

当前走弱的根因排序：

1. 美国/伊朗和谈预期升温，特朗普表态偏软，油价地缘溢价退潮。
2. 粤桂资金面确认退潮：5/25 L2 `-1.74 亿`、超大单 `-1.06 亿`、CVD `-2.45 亿`。
3. 硫磺/硫酸仍高位，但从“单边上涨”转成“高位拉锯”。
4. Q1 业绩强已经兑现，经营现金流为负的问题在退潮时会被放大。
5. 定增和湿法磷酸是中期故事，不是短线硬催化。

粤桂从“反抽减仓”变回“继续持有”的条件：

- 伊朗谈判失败或霍尔木兹/军事风险重新升温。
- Brent 重新站回关键位并继续上行。
- 硫磺港口库存继续紧、成交价高位不松，硫酸高价稳定。
- 粤桂出现湿法磷酸投料试车、客户/订单、定增审核明显推进。
- 盘面看到 L2 转正、CVD 修复、热点排名回升，冲高不再被砸。
