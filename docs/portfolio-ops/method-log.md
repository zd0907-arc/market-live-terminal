# 分析方法迭代日志

## 2026-05-26 初始规则

- 每天不能只按当日强弱做买卖结论。
- 先判断持仓买入逻辑是否失效，再比较新候选是否值得换仓。
- L2、尾盘挂单、盘口异常只作为执行层信号，不单独推翻中短线持仓逻辑。
- 对用户已有亏损仓，不能默认“弱就卖”；必须考虑低位区间、主线概率、资金异动和卖飞风险。
- 当大盘异常波动时，要区分个股自身问题和市场系统性冲击。
- 系统候选买入后，后续评估必须回看当初模型来源和原始买入理由。
- 每只实盘持仓必须先有公司研究卡，明确业务、利润驱动、财报变量、新闻关键词和失效条件。
- 每日持仓复盘必须包含公司与消息面检查，不能只看 L2 和价格。
- 对星火机会模型买入的票，必须按 22 个交易日冲高窗口跟踪，记录信号日、买入价、窗口剩余、最高涨幅、距离 15% 目标差距；不能用普通日内弱强逻辑随便否定。
- 对商品链个股，必须追踪上游商品和地缘驱动。粤桂股份的关键外部变量包括原油、伊朗局势、特朗普/和谈表态、硫磺/硫酸价格。

## 待验证问题

- 星火模型候选买入后，最佳持有周期是否接近 3/5/10/22 个交易日。
- 当候选买入后连续弱于市场时，几天后减仓更优。
- 热点共振对星火候选是增强因素还是拥挤风险。
- 大仓位单票是否需要固定最大仓位约束。
- 换仓规则是否优于原持仓等待反抽。
