# 选股研究与回测闭环

## 覆盖 CAP
- `CAP-SELECTION-RESEARCH`

## 当前正式结论
1. 选股研究结果的正式主链语义是 `selection_research_main`：Windows 现役物理名就是 `selection_research.db`；旧 `selection_research_windows.db` 已退休；Mac 主读外置 `market-data/research/current/selection/selection_research.db`；repo 内 `data/selection/selection_research.db` 只按回退 / 兼容副本理解。
2. 候选、画像、回测、策略评估接口已经存在，主链路可用。
3. 当前产品入口已经从单策略候选页推进到“每日复盘决策”，并接入候选票研究上下文包：公司概况、决策解释、研究依据、事件覆盖、价格/L2 序列可统一查询。
4. 当前判断要保守：选股模块已经能支持研究和观察，但策略表现、覆盖面、摘要质量和实时可交易性还没有达到稳定自动买入信号标准。

## 当前已接入策略
- 资金流回调稳健：质量较高但覆盖面窄，适合观察盘和继续模拟验证。
- 趋势中继高质量回踩：已接入页面，但样本少，不能把少量成熟样本当成充分稳定结论。
- 消息事件重估：已收口为候选票事件解释卡 / 消息触发快速研判卡，尚未开发为正式策略。

## 当前策略使用边界
- 选股信号是研究候选和复盘入口，不是自动交易指令。
- `breakout + 热点共振` 当前验证偏负，不能把热点板块直接做成策略加分项。
- 市场热点研究当前只允许作为解释标签、拥挤度提示、风险提示或独立追强候选池，不回写到正式选股打分。
- 小主题强者恒强追强池已验证出“后20日冲高概率”优势，但必须配合卖点；不能理解为热点自动买入系统。

## 当前市场环境辅助判断（2026-06-11 / v5.2.17）
- 关联变更卡：`docs/changes/REQ-20260611-01-selection-market-trend-ui.md`
- 选股研究工作台已把市场环境水位作为左侧候选导航的首屏辅助判断：展示最近 90 个交易点的市场水位趋势，并给出当前防守/观察/进攻状态与默认操作建议。
- 该能力用于回答“今天推荐票能不能参与”的环境问题，不改变四类来源本身的候选生成与排序。
- 用户交互上，鼠标悬停趋势图可查看选中交易日的日期、水位分数和市场状态；弱势证据通过标题后的感叹号 hover 展示。
- 当前默认原则保持防守优先：市场处于防守环境时，页面建议暂停新开仓或仅观察，最终操作仍由用户人工决策。

## 当前热点研究结论（2026-05-06）
- 纯小主题热点不能直接买，热点池内后排票会拖累收益。
- L2 资金流入可以辅助排序和排雷，但单因子不能稳定预测未来收益。
- 强者恒强规则可用于筛出未来20日有冲高概率的样本：热点日涨幅、前20日涨幅、前5日超大单占比、主题成交放大同时满足时，后20日最高涨幅超过20%的历史命中率明显提高。
- 2025 年 100万单账户回测显示：分批止盈版收益 `+24.2%`，去掉分批止盈后仅 `+1.9%`，固定持有20日为 `-14.2%`。
- 当前可沉淀为研究机制：先用热点与价格强度找候选，再用 L2/回撤/时间退出做交易管理。

## 当前热点联动研究结论（2026-06-03）
- `热门板块正式上榜后，再和现有选股模型做前置过滤联动` 已完成正式收口，不作为主策略继续推进。
- 原因不是它完全无效，而是它只在部分窗口有效，跨市场阶段稳定性不够，`2026-01 ~ 2026-04` 的较优组合到 `2026-05` 外样本已明显失效。
- 这条线当前只保留为研究证据，不回写到正式选股打分，也不单独包装成新正式模型。
- 如果未来继续做热点方向，研究重点应转向 `提前识别趋势形成过程`，而不是继续优化“热点上榜后过滤”。
- 对应正式结论文档：`docs/selection/hot_theme_prefilter_selection_2026-06-02/final_closure.md`。
