# 散户一致性观察

## 覆盖 CAP
- `CAP-RETAIL-SENTIMENT`

## 当前正式结论
1. 当前正式源以股吧单源为主。
2. 首页消费已收口到 overview / heat_trend / feed / daily_scores 等结构化结果。
3. 这是正式能力，但还不是“全源、全语义”完成态。

## 运行红线
- 首页 `散户一致性观察` 默认只能读本地库缓存，不允许在页面初始化、驻留轮询或普通刷新里自动触发 `POST /api/sentiment/crawl/{symbol}`。
- 补抓只能由用户显式点击“立即补抓”，或由盘后 / 夜间日常任务统一执行；不能把远端抓数挂到页面打开时机。
- 这条红线来自 `2026-05-26` 一次真实事故：页面自动补抓走同步远端抓数，链路包含翻页、详情抓取、回复抓取与落库，最终把本地后端拖成“`/api/health` 正常，但 history / sentiment 等业务接口长期转圈或超时”。

## 当前仍需继续做的
- 更长历史覆盖
- reply 等非主帖事件的进一步稳定化
- 若未来引入新源，必须重新建卡冻结
