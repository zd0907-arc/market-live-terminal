# 模型评估指标字典

更新时间：2026-06-03

## 结论

以后讨论模型效果，优先用业务语言，再给对应指标。

不要再只说 `hit20`、`runup`、`pain` 这种缩写，让人猜意思。

## 1. 先分清两类评估

### 纯选股评估

只回答一个问题：

- 模型挑出来的票，后面会不会涨、能涨多高、稳定不稳定。

### 实盘回放 / 交易评估

回答的是另一件事：

- 真按规则买卖，最后赚没赚钱；
- 持仓周期、仓位、卖点、滑点会不会把纸面优势吃掉。

以后任何结果都要先说明自己属于哪一类。

## 2. 纯选股常用指标

### 22 日最大冲高

定义：

- D 日盘后出信号
- 以 D+1 开盘价作为成本基准
- 看未来 22 个交易日内最高价，相对 D+1 开盘价最多涨了多少

### Top1 平均冲高

定义：

- 每个交易日只看模型排第 1 的那只票
- 统计它们 22 日最大冲高的平均值

### Top1 中位数冲高

定义：

- 还是只看每天第 1 名
- 但不是算平均，而是看中位数

它更能反映“平时到底稳不稳”。

### Top3 支持度

定义：

- 看每天前 3 名里，整体质量怎么样

它回答的是：

- 如果产品上给用户 3 个候选，而不是只给 1 个，这个池子有没有选择价值。

## 3. 命中率类指标

### 冲高 5% 命中率

- 模型选出的票，未来窗口里最高价至少比 D+1 开盘价高 5% 的比例

### 冲高 10% 命中率

- 模型选出的票，未来窗口里最高价至少比 D+1 开盘价高 10% 的比例

### 冲高 20% / 30% 命中率

- 适合看进攻型模型能不能抓到更大的波段

## 4. 风险类指标

### 坑票率

建议统一看两档：

1. `0% 冲高都没有`
   - 买完后最高价都没超过买入成本
2. `连 3% 冲高都没有`
   - 买完后连最基本的短线缓冲都没给过

这才是“买到就难受”的核心指标。

### 最大回撤压力

诊断：

- 选出来的票，在给出最高冲高之前，先向下砸过多少

## 5. 稳定性指标

### 月度稳定性

- 不只看全样本平均
- 要分月份看，每个月是否都大体成立

### 样本覆盖数

- 实际参与统计的交易日数、候选票数

没有样本量的高收益，参考价值很弱。

## 6. 实盘回放常用指标

### 最终收益率

- 从初始资金出发
- 按完整买卖规则回放后，最后赚了多少

### 胜率

- 每笔真实交易里，赚钱的比例

### 平均单笔收益 / 中位单笔收益

- 平均值看期望
- 中位数看平时手感

### 最大回撤

- 模型中途最痛的时候有多痛

### 资金利用率

- 模型是不是长期空仓
- 或者长期只押一只票，导致效率太低

## 7. 针对不同模型，优先看什么

### 22 日纯选股模型

优先看：

1. Top1 中位数冲高
2. 冲高 5% / 10% 命中率
3. 坑票率
4. 月度稳定性
5. Top1 平均冲高

### 次日 / 超短模型

优先看：

1. 次日最大冲高
2. 次日是否至少给到正收益空间
3. 次日坑票率
4. 次日尾盘表现

### 持仓 / 卖点模型

优先看：

1. 是否减少大回撤
2. 是否保住主要盈利段
3. 是否明显减少卖飞或过早止盈

### 热点过滤 / 市场环境过滤

优先看：

1. 加了过滤后，坑票率是否下降
2. 加了过滤后，样本是否被误杀太多
3. 加了过滤后，月度稳定性是否更好

## 8. 以后汇报结果的最小格式

以后每次汇报一个模型，至少按这个顺序说：

1. 这是纯选股评估，还是实盘回放
2. 时间范围
3. 样本数
4. Top1 / Top3 的核心结果
5. 坑票率
6. 月度稳定性
7. 再补充极端亮点

不要再先报一个很夸张的收益数字，再让人猜它到底是什么口径。
