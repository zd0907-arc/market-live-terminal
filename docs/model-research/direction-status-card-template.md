# 研究方向状态卡模板

更新时间：2026-06-04

## 作用

以后每新增一个模型研究方向，都建议先补一张状态卡。

## 模板

```md
# <方向名称>

更新时间：<YYYY-MM-DD>

## 结论

一句话说明：
- 这个方向当前有没有价值
- 当前是继续推进、暂停观察，还是只保留历史参考

## 它在解决什么问题

- 用业务语言解释目标

## 它和现有方向的区别

- 和星火 1.0 的区别
- 和星火 v2 的区别
- 和热点 / 市场过滤 / 持仓模型的边界

## 当前状态

可选枚举：

- `构想中`
- `研究中`
- `已有首轮结果`
- `正在验证`
- `已形成稳定结论`
- `已接入产品`
- `暂停`
- `归档`

## 当前主资料入口

- 列 3~8 个最关键文档

## 当前结论

- 当前最重要的 3~5 条结论

## 当前未解决问题

- 还差什么

## 是否允许接入产品

- `允许`
- `不允许`
- `只允许研究展示`

## 下一步建议

- 只列最关键的 1~3 步
```
