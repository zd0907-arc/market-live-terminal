# REL-20260507 v5.1.1 长期趋势研究 API 补丁

## 1. 发布结论
- 版本号：`v5.1.1`。
- 目的：把 2026-05-07 生成的长期趋势研究 API 纳入 main、GitHub 和云端。

## 2. 包含内容
- `GET /api/trend-research/ideas`：返回当前长期趋势线索列表。
- `GET /api/trend-research/ideas/{idea_id}/dashboard`：返回存储主线看板数据、估值情景、日报 Markdown。
- 当前已接入 `storage` 线索，读取 `data/selection/long_term_trends/storage/` 与 `docs/selection/long_term_trends/storage/`。

## 3. 边界
- 这是本地研究能力的 API 化，不代表自动交易信号。
- Cloud 仍以盯盘 + 复盘为必保；该 API 即使部署到云端，也只是轻量只读研究接口。
