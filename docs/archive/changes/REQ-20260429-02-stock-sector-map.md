# REQ-20260429-02 股票-板块映射补全

## 目标

把“每只股票属于哪些板块”先补成稳定本地数据层，后续市场热度、选股解释、策略验证都从同一份映射读取。

## 第一版范围

- 数据源：东方财富公开行情接口。
- 板块类型：
  - `concept`：概念板块
  - `industry`：行业/细分行业板块
- 本地落地：
  - SQLite：`market_heat/stock_sector_map.db`
  - JSON：`market_heat/stock_sector_map_latest.json`
  - JSON：`market_heat/sector_boards_latest.json`

## 使用原则

- 板块成分股按当前公开口径近似回填历史，不解决历史成分变更问题。
- 每日收盘后或研究前手工刷新即可，不做复杂自动化。
- 先用于研究解释和影子回测，不直接改变实盘策略。

## 后续接入

1. 市场热度：从完整板块成分股重算全市场板块热度。
2. 选股验证：统计选股候选是否处于当日高热板块。
3. 候选解释：展示“这只票属于哪些正在升温/退潮的板块”。
