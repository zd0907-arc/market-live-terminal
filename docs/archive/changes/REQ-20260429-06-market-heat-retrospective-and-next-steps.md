# 热点板块研究完整复盘与下一步建议

## 一句话结论

这次小项目已经完成第一阶段研究闭环：

```text
热点板块能解释“强股更容易从哪里来”，但不能直接产生可买收益。
它暂时不适合作为买入加分器，更适合作为研究解释标签和突破策略的风险提示标签。
```

最重要的实战发现：

```text
breakout + 热点共振，历史上不是更强，而更像追高/接盘风险。
breakout + climax_hot 是目前最有价值的负向风险标签。
stealth + new_hot 有小样本机会，但还不能规则化。
```

## 这个小项目最初要解决什么

用户问题不是“做一个热门板块页面”，而是：

```text
如果连市场热点都不知道，研究股票会很傻。
但如果又把平台做得过重，会重新陷入做系统而不是研究股票。
```

所以本项目目标被定为：

```text
用尽量轻的工程方式，建立每日市场热点感知能力；
再用历史数据验证：热点能不能帮助现有选股策略提高胜率、收益或排雷能力。
```

最终定位从一开始就不是“热点直接买入”，而是候选方向：

```text
策略信号底座 + 热点感知辅助 + 必要时做风险提示
```

## 我们实际做了什么

### 1. 建立股票-板块映射

先补了全市场股票属于哪些板块/概念的基础数据。

当前数据规模：

```text
股票覆盖：3180 只
原始板块：972 个
股票-板块映射：49579 条
```

价值：

```text
后续任何“这只票是否属于当前热点”的判断，都不再靠临时猜测，而是有本地映射表可查。
```

### 2. 做板块清洗

发现东方财富原始板块里有大量不适合代表市场主线的标签，例如：

```text
融资融券、沪股通、指数成分、机构重仓、地域板块、昨日涨停、财报预增、市值风格等
```

这些标签不是“题材/产业逻辑”，会污染热点识别。

所以增加了清洗规则，保留更接近交易主题的行业/概念。

### 3. 先做大主题层，但发现太粗

最初合并出 18 个大主题，例如：

```text
AI算力硬件
液冷/温控
半导体设备/存储
创新药/CXO
电池/储能
军工/船舶/商业航天
```

这个层适合人理解市场主线，但不适合做交易过滤。

原因：

```text
大主题 Top3 覆盖约 25% 市场
大主题 Top5 覆盖约 40% 市场
```

覆盖太宽，后排杂毛太多，无法形成有效收益判断。

### 4. 压细到细颗粒热点层

后来改用“细概念/细行业”，并限制成员数：

```text
成员数：5 ~ 80 只股票
候选细板块：约 635 个
```

示例：

```text
CPO概念
光通信模块
通信线缆及配套
液冷概念
固态电池
低空经济
商业航天
医疗研发外包
贵金属
```

当前最佳基础口径：

```text
细颗粒热点 Top15
+ 股票与板块 D 日同向上涨
```

结果：

```text
覆盖率压到约 5%
达到了“5%~10% 甚至更低”的目标
```

这是本项目第一个成功点。

## 我们做过哪些验证

### 验证一：纯热点池能不能找到未来强股

近一年结果：

```text
D+3:
Coverage 5.2%
Recall 10.9%
Lift 2.08
Alpha -0.13%

D+5:
Coverage 5.3%
Recall 10.3%
Lift 1.96
Alpha -0.14%
```

解释：

```text
Lift 接近 2，说明未来强股确实更容易来自细颗粒热点。
但 Alpha 为负，说明热点池内部大量后排票拖累收益。
```

结论：

```text
热点能解释强股来源，但不能直接买。
```

### 验证二：叠加 L2 龙头过滤

尝试逻辑：

```text
热门细板块 Top15
+ 板块内 L2 主力净流入 Top40%
+ 收盘封死涨停豁免 L2
```

近一年结果：

```text
D+3:
Coverage 2.0%
Recall 6.2%
Lift 3.06
Alpha -0.20%

D+5:
Coverage 2.0%
Recall 5.8%
Lift 2.87
Alpha -0.28%
```

解释：

```text
L2 能进一步提高 Lift，但没有改善 Alpha。
它能帮助识别“强股集中在哪里”，但不能解决接盘和后排回撤问题。
```

结论：

```text
L2 不能当硬过滤，只能当二级解释标签。
```

### 验证三：现有策略候选 + 热点共振 A/B

这是最关键的一次验证。

原假设：

```text
如果策略选出的票同时命中热点，应该更值得买。
```

结果相反。

近一年 Top20 候选：

```text
breakout / D+5:
Baseline       +0.60%，Alpha -0.03%，胜率 46.7%
Resonance      +0.13%，Alpha -0.50%，胜率 40.6%
Non-resonance  +0.75%，Alpha +0.12%，胜率 48.7%
```

解释：

```text
breakout 本来就是价格已经异动的票。
如果它又处在全市场最热题材里，往往不是启动，而是过热、拥挤、追高。
```

结论：

```text
热点共振不能给现有策略加分。
尤其对 breakout，热点共振偏负。
```

### 验证四：生命周期分层

继续拆成：

```text
new_hot：刚冲入热点
continuing_hot：持续热门
climax_hot：多日高位热门
```

breakout 结果：

```text
D+5:
Non-resonance  +0.75%，Alpha +0.12%，胜率 48.7%
new_hot        -0.27%，Alpha -0.90%，胜率 39.3%
continuing_hot +0.49%，Alpha -0.14%，胜率 42.2%
climax_hot     -0.64%，Alpha -1.28%，胜率 35.5%
```

更严格 climax：

```text
breakout / climax_hot / D+5:
样本 15，均值 -4.10%，Alpha -4.73%，胜率 26.7%
```

结论：

```text
new_hot 并不是 breakout 的启动加分项。
climax_hot 是明显风险标签。
```

### 验证五：模拟排雷规则

进一步验证：如果剔除风险标签，整体策略是否改善。

breakout：

```text
D+5:
Baseline                +0.60%
Exclude climax          +0.63%
Exclude new+climax      +0.71%
Non-resonance only      +0.75%

D+10:
Baseline                +1.40%
Exclude climax          +1.44%
Exclude new+climax      +1.56%
Non-resonance only      +1.70%
```

结论：

```text
只剔除 climax 方向正确，但样本少，整体提升小。
剔除 new+climax 改善更明显，但规则更激进。
只保留非热点共振历史最好，但会砍掉约 25% 候选，不能直接上线。
```

## 哪些结论有价值

### 已经比较确定的结论

```text
1. 细颗粒板块口径是必要的，大主题太粗。
2. 细颗粒 Top15 + 日内共振能把覆盖率压到约 5%。
3. 热点对未来强股有解释力，Lift 长期 > 1。
4. 热点池不能单独买，Alpha 长期不转正。
5. L2 过滤能提高 Lift，但不能改善收益。
6. breakout + 热点共振偏负，不应加分。
7. breakout + climax_hot 是强风险提示。
```

### 有一定价值但还不够稳定的结论

```text
1. stealth + new_hot 在 D+3 有改善。
2. 但样本只有几十个，不能规则化。
3. 可以作为“稀缺观察池”，后续每天滚动看。
```

### 被证伪或暂时失败的想法

```text
1. 热点板块直接作为买入池：失败。
2. 热点共振作为策略加分项：失败。
3. breakout + new_hot 是启动机会：失败。
4. L2 龙头过滤能让热点池 Alpha 转正：失败。
5. 直接把 climax_hot 一票否决：暂不成立，只能影子提示。
```

## 这次最大的经验教训

### 1. 热点不是收益来源，而是拥挤度信息

热点确实告诉我们资金在哪里，但它也告诉我们：

```text
哪里可能已经太拥挤。
```

尤其对 breakout 来说，热点共振更像“全市场都看见了”，不是“低位刚被发现”。

### 2. Lift 和 Alpha 必须分开看

本项目最关键的量化经验：

```text
Lift 高，不代表能赚钱。
```

热点能提高未来强股命中率，但如果池子里更多后排下跌，Alpha 仍然会是负的。

### 3. 不要把解释变量误当交易信号

板块热度适合回答：

```text
这只票为什么被市场关注？
它有没有题材背景？
它是不是处在拥挤交易里？
```

但不适合直接回答：

```text
明天该不该买？
```

### 4. 这类研究应该先影子验证，再接入策略

如果直接按直觉把热点加权，结果会伤害策略。

这次避免了一个很大的坑。

## 接下来怎么办

### 建议一：结束“第一阶段热点研究”，不要继续调参挖收益

当前已经足够说明：

```text
热点本身不是买点。
再继续调 TopK、窗口、阈值，很容易走向过拟合。
```

建议把第一阶段正式收口。

### 建议二：只做轻量影子接入

不要改策略分数，不要影响买卖列表。

只给候选股补影子字段：

```text
fine_hotspot_hit
fine_hotspot_name
fine_hotspot_rank
fine_hotspot_stage
is_breakout_hotspot_risk
is_breakout_climax_risk
is_stealth_new_hot_watch
```

用途：

```text
每天复盘时解释：这只票是不是题材票？
如果是 breakout，是否处于过热风险？
如果是 stealth，是否有低位补涨观察价值？
```

### 建议三：未来 20~40 个交易日做前向观察

每天记录，不修改策略：

```text
策略原始候选
热点影子标签
D+1 / D+3 / D+5 表现
```

重点看：

```text
breakout + climax_hot 是否继续显著差
breakout + 任意热点共振是否继续偏负
stealth + new_hot 是否还能出现 D+3 优势
```

如果前向观察继续支持，再考虑规则化。

### 建议四：每日研究工作流里使用，而不是先做复杂页面

你每天问 Codex 时，可以让 Codex 输出：


这比先做复杂系统更符合现在的方向。

### 建议五：页面只做一张轻量辅助视图

验证口径：

```text

D+5:
all_low_l2        样本 290，均值 +1.13%，Alpha +0.49%，胜率 56.5%
```

结论：

```text
这是目前热点研究里第一个比较像“可策略化雏形”的方向。

有效组合不是单纯缩量，而是“缩量或平量 + L2 连续流入”。
它和现有 stealth 信号重合很少，暂时应视为独立的热点低位补涨策略，而不是旧 stealth 的简单增强版。
```

## 追加验证：热点低位 L2 补涨参数稳健性

这一步专门防止过拟合，不再只看单一最佳参数，而是看一组相近参数是否都有效。

纳入的新防呆：

```text
1. 20日位置：<=0.5 / 0.65 / 0.8
2. 60日均线乖离：不限制 / <=8% / <=5%
3. 5/10/20均线粘合：不限制 / <=6% / <=4%
4. 量能比：0.5~1.0 / 0.5~1.2 / 0.8~1.2
5. 超大单：连续2日 / 3日中2日 / 3日合计为正 / 不限制
6. 样本低于80：只作为观察，不作为主参数
```

核心发现：

```text
1. 稳定组合大量存在，不是单一参数偶然跑出来。
2. D+5 上，样本达标组合普遍能做到 Alpha +1.7% ~ +2.1%。
3. “3日中2日超大单流入”反复出现在高排名组合里，比“必须连续2日”更稳。
4. 量能比 0.5~1.2 是更合理主口径；既避免绝对地量，也避开放量滞涨。
5. 60日均线乖离 <=8% 有帮助，但不必过度收紧到 <=5%，否则样本会塌方。
6. 均线粘合有帮助，但不是必要硬条件；可作为加分/解释项。
```

可作为下一步主观察口径：

```text
热点阶段：过去5日内有2~3日进入细颗粒热点Top10
个股位置：20日位置 <= 0.65 或 <=0.8
量能：D日成交额 / D-10~D-1均额 在 0.5~1.2
资金：D/D-1 L2主力净流入 + 过去3日有2日超大单净流入
结构防呆：60日均线乖离最好 <=8%
收益观察：优先看 D+3 / D+5
```

代表性达标结果：

```text
热点Top10，2~3/5日，pos20<=0.8，amount 0.5~1.2，ma60<=8%，super=2of3：
D+5 样本 87，均值 +2.70%，Alpha +2.07%，胜率 65.5%

热点Top10，2~3/5日，pos20<=0.65，amount 0.5~1.2，super=2of3：
D+5 样本 98，均值 +2.44%，Alpha +1.81%，胜率 62.2%
```
