## 22 日机会发现模型

定位：

```text
D 日盘后，从全市场主板 10cm 股票里找 D+1 值得重点看的 Top1。
目标是未来 22 个交易日内出现足够高冲高机会，不是预测次日涨跌。
```

历史验证结论：

| 指标 | 结果 |
|---|---:|
| Top1 未来 22 日冲高 >=15% | 65.38% |
| 严格账户回测最佳收益 | +87.58% |
| 严格账户回测交易数 | 13 |
| 主要限制 | 样本少，离场壳粗，未完成真实前推 |

处理结论：

```text
保留为后续每日盘后综合候选来源。
不要把它单独叫自动交易策略。
```

## 短周期 H5 实验

来源目录：`short_horizon_v0_1/`

最佳整体结果：

| 口径 | 结果 |
|---|---:|
| 持有周期 | 5 日 |
| 退出规则 | 8% 止盈 / 无硬止损 / 5 日到期 |
| 交易数 | 25 |
| 总收益 | +40.60% |
| 最大回撤 | -10.45% |
| 胜率 | 60.00% |

处理结论：

```text
H5 对短线启动确认有参考价值。
2/3 日超短线整体不稳定。
H5 不作为独立主策略，不保留模型和中间 CSV。
```

## H5 + 22 日融合实验

来源目录：`fusion_h5_22_v0_1/`

核心结论：

| 方案 | 交易壳 | 收益 | 结论 |
|---|---|---:|---|
| 22 日 Top1 基线 | 22 日持仓壳 | +87.58% | 当前最好 |
| H5 重排 70/30 Top1 | 22 日持仓壳 | +69.00% | 不如基线 |
| H5 重排 50/50 Top1 | 22 日持仓壳 | -2.83% | 明显失败 |
| 22 日 Top1 + H5 前 10 确认 | H5 5 日壳 | +35.57% | 短线确认有价值 |

处理结论：

```text
不要用 H5 直接重排 22 日模型。
更合理的用法是：22 日模型负责主选股，H5 作为短线启动确认标签。
```

## 旧滚动验证

| 验证窗口 | 天数 | hit15 | 平均 22 日最大冲高 | 最佳账户收益 | 主要问题 |

处理结论：

```text

旧 split 目录体积大，保留本摘要即可。
```

## 清理后产品方向

每日盘后工作台后续应按统一来源展示：

```text
选日期
→ 综合候选结果
→ 来源徽标：规则策略 / 机会发现模型 / 后续新模型
→ 单票解释：为什么入选、适合观察还是行动、风险和持仓动作
```

不要再让用户每天手动下拉选择策略。
