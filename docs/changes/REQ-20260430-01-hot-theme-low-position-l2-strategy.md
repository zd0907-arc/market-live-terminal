# 热点低位 L2 补涨策略说明

## 核心结论

这是目前“热门板块研究”里第一个值得进入前向观察的策略雏形。

它不是追最强龙头，也不是看到热门板块就买，而是寻找：

```text
板块已经热起来，但还没完全高潮；
个股还在低位，没有放量乱冲；
L2 主力连续净流入；
超大单过去 3 天里有 2 天在进；
股价没有明显远离 60 日生命线。
```

人话版：

```text
热点扩散时，资金可能从前排高位龙头切到板块内低位补涨票。
我们要找的是“低位 + 不放量滞涨 + 主力/超大单提前埋伏”的票。
```

## 当前主观察口径

```text
热点阶段：过去 5 日内有 2~3 日进入细颗粒热点 Top10
个股位置：20 日位置 <= 0.8
近 5 日涨幅：-8% ~ 5%
趋势结构：60 日均线乖离 <= 8%
量能：D 日成交额 / D-10~D-1 平均成交额 在 0.5 ~ 1.2
主力资金：D 日和 D-1 日 L2 主力净流入
超大单：过去 3 日有 2 日超大单净流入
买入观察口径：D+1 开盘
收益观察窗口：D+3 / D+5
```

## 已验证结果

主周期：

```text
2025-04-16 ~ 2026-04-28
约 250 个交易日
```

原始低位 L2 补涨：

```text
D+3：样本 290，均值 +1.03%，Alpha +0.65%，胜率 56.2%
D+5：样本 290，均值 +1.13%，Alpha +0.49%，胜率 56.5%
```

```text
放量滞涨组：-0.04%，Alpha -0.67%
```

结论：

```text

```

叠加超大单后：

```text
缩量/平量 + 超大单连续 2 日：
D+5 样本 98，均值 +2.32%，Alpha +1.69%，胜率 61.2%
```

参数稳健性验证显示：

```text

样本达标组合里，D+5 Alpha 大多在 +1.7% ~ +2.1% 左右。
```

代表组合：

```text

量能比 0.5~1.2；
60 日乖离 <= 8%；
过去 3 日有 2 日超大单净流入。

D+5：样本 87，均值 +2.70%，Alpha +2.07%，胜率 65.5%。
```

## 成功点

```text
1. 热点不是买点，但热点扩散阶段有补涨机会。
2. 低位票必须配合资金埋伏，否则只是弱。
3. L2 主力连续净流入是基础门槛。
4. 超大单 3 日中 2 日净流入比“必须连续 2 日”更稳。
5. 量能比 0.5~1.2 很关键，既避开死水，也避开放量滞涨。
6. 60 日乖离 <= 8% 有助于避免下跌半山腰。
```

## 失败或风险点

```text
1. 纯热点池不能买，Alpha 不稳定。
2. 热点 + breakout 反而偏追高风险。
3. new_hot + breakout 没有验证出启动加分。
4. 新热点资金龙头整体没跑出来，高开 5% 以上风险很大。
5. 挂单/CVD/OIB 数据样本太少，目前不能作为主判据。
6. 最近严格口径不一定每天有候选，这是策略稀缺性的一部分。
```

## D+1 冲高回落深挖

关键修正：

```text
D+1 冲高回落不是买入前过滤条件。
因为如果买入点是 D+1 开盘，当时还不知道当天会不会冲高回落。

它更适合做：
1. D+1 收盘后的持仓确认。
2. D+1 当天的风险处置。
```

分组结果：

```text
D+1 不冲高回落：
样本 40，D+1 均值 +2.37%，D+3 均值 +4.11%，D+5 均值 +5.68%，D+5 胜率 85.0%，最差 D+5 -3.87%

D+1 冲高回落：
样本 47，D+1 均值 -1.39%，D+3 均值 -0.70%，D+5 均值 +0.17%，D+5 胜率 48.9%，最差 D+5 -15.99%
```

但是不能简单“一冲高回落就卖”：

```text
基准：全部持有到 D+5
均值 +2.70%，胜率 65.5%，最差 -15.99%

只要 D+1 冲高回落就 D+1 收盘退出
均值降到 +1.86%，胜率降到 44.8%

D+1 <= -2% 才退出
均值仍为 +2.70%，最差改善到 -8.80%
```

当前更合理的交易解释：

```text
1. D+1 不冲高回落 = 强持仓确认，可以继续拿到 D+3/D+5。
2. D+1 冲高回落但跌幅不深，不一定马上死掉，很多样本后续会修复。
3. D+1 冲高回落且从开盘算亏损超过 2%，才是更明确的风险处置点。
4. 这条规则目前更像“尾部风险控制”，不是提高平均收益的进攻规则。
```

### 冲高回落定义

当前代码定义：

```text
回落比例 = (D+1 最高价 - D+1 收盘价) / (D+1 最高价 - D+1 最低价)

满足任一条件即判定为 D+1 冲高回落：
1. 回落比例 > 0.5，也就是收盘落在全天振幅下半区；
2. D+1 最高价 > 开盘价，且收盘价 < 开盘价，也就是盘中冲过、最后收绿。
```

操作语言：

```text
D+1 开盘买入后，到收盘看：
- 收盘在全天振幅上半区，且没有收绿：不冲高回落，强确认。
- 收盘在全天振幅下半区，或者冲高后收绿：冲高回落，进入风险观察。
- 如果同时从开盘价算已经亏超过 2%：优先止损/降仓。
```

## 卖出时机验证

固定持有窗口：

```text
全部样本：
D+1 +0.34%，D+2 +0.79%，D+3 +1.51%，D+4 +2.15%，D+5 +2.70%，D+10 +3.84%

D+1 不冲高回落：
D+1 +2.37%，D+2 +3.26%，D+3 +4.11%，D+4 +5.00%，D+5 +5.68%，D+10 +6.19%

D+1 冲高回落：
D+1 -1.39%，D+2 -1.31%，D+3 -0.70%，D+4 -0.28%，D+5 +0.17%，D+10 +1.84%
```

卖出测试结论：

```text
1. D+5 不是完美卖点，但它是当前样本里比较稳的默认结束点。
2. D+1 不冲高回落后，收益主要在 D+3~D+5 继续释放，过早止盈会砍掉大赢家。
3. 单纯 +5% 或 +10% 止盈会降低均值，因为这个策略的大收益来自少数扩散成功的大票。
4. 单纯 -2%/-3% 止损会降低胜率和均值，但能改善尾部亏损。
5. 当前最合理的第一版卖出框架是：
   - D+1 收盘确认；
   - D+3 第一次复核；
   - D+5 默认结束；
   - D+1 冲高回落且亏损超过 2% 时提前退出/降仓。
```

## 重要修正：尾盘确认买入，而不是 D+1 开盘买入

更符合实际操作的方式：

```text
D 日盘后：系统给出热点低位 L2 信号。
D+1 尾盘：根据当天走势确认是否买入。
```

尾盘买入判定：

```text
1. 当天不冲高回落：
   (最高价 - 当前价) / (最高价 - 最低价) <= 0.5
   且 当前价 >= 开盘价

2. 当天涨幅不能太大：
   从 D+1 开盘价算，当前涨幅最好在 0%~2%
   <=2% 可以作为主买点
   >2% 不作为主买点
   >5% 原则上不追

3. 仍然满足原始结构：
   低位、量能不爆、热点仍在、L2/超大单没有明显反向。
```

历史验证：

```text
D+1 不回落全部尾盘买：40 只次
固定 D+5 参考：均值 +3.24%，胜率 60.0%
动态卖出：均值 +3.99%，最差 -4.50%

D+1 不回落且当天涨幅 <=2% 尾盘买：24 只次
固定 D+5 参考：均值 +3.46%，胜率 75.0%
动态卖出：均值 +5.50%，最差 -2.44%

D+1 不回落但当天涨幅 >2% 再尾盘买：16 只次
固定 D+5 参考：均值 +2.92%，中位数 -1.54%，胜率 37.5%
动态卖出：均值 +1.71%，中位数 -1.25%，胜率 25.0%
```

结论：

```text
尾盘确认买入的核心不是“不冲高回落”一个条件。
更关键的是：不冲高回落 + 当天涨幅没有透支。
当前主买点应收窄到 D+1 不回落且从开盘算涨幅 <=2%。
```

## 动态卖出框架

不采用固定天数卖出。固定 D+3/D+5/D+10 只作为研究窗口，不是交易规则。

当前动态卖出信号：

```text
硬风控：
- 买入后收盘亏损 <= -5%

价格 + 资金转弱：
- 收盘亏损 <= -3%
- 且主力/超大单连续 2 天同时净流出

超大单撤退：
- 持仓期累计超大单从峰值回撤 >=25%
- 且连续 2 天下降
- 且收益未明显打开

暴力流出：
- 当日主力和超大单同时净流出
- 且超大单流出占持仓期累计成交额 >=1.8%

板块退潮：
- 所属热点连续 2 天跌出 Top15
- 且个股跌破 5 日线

盈利回撤：
- 持仓浮盈曾 >=8%
- 从高点回撤 >=5%
- 且资金转负
```

当前这组动态卖出还只是第一版：

```text
优点：比固定 D+5 更贴近真实交易，能明显压低尾部亏损。
问题：胜率和中位数还不够好，主要是部分 theme_fade_below_ma5 退出过早，需要继续拆。
```

## 规则5卖出质量归因：板块退潮 + 破均线

```text

用 D+1 收盘价近似尾盘买入价
```

```text

```

实际验证不支持这个担心：

```text

均值 +1.71%，中位数 +1.50%，最大 +4.15%
```

## 大肉路径深挖：D+3 复核比 D+1 更关键

这次只看当前最可执行的主买入口径：

```text
D 日：出现热点低位 L2 信号。
D+1 尾盘：不冲高回落，且从 D+1 开盘算涨幅 <= 2%。
买入价格近似用 D+1 收盘价。
样本数：24 只次。
```

为避免偷看，MFE 只从 D+2 到 D+20 的盘中高点计算，不把 D+1 买入前的盘中高点算进去。

分层结果：

```text
大肉组：MFE20 >= 10%，7 只次
- D+3 收盘均值 +4.07%
- D+5 收盘均值 +9.02%
- D+20 收盘均值 +24.57%
- MFE20 均值 +39.83%

中肉组：MFE20 5%~10%，8 只次
- D+3 收盘均值 +0.84%
- D+5 收盘均值 +2.08%
- D+20 收盘均值 +0.34%

小肉组：MFE20 < 5%，9 只次
- D+3 收盘均值 -0.22%
- D+5 收盘均值 +0.35%
- D+20 收盘均值 -1.20%
```

核心发现：

```text
D+1 尾盘只能解决“能不能买”。
能不能从小套利变成大肉，D+3 开始明显分化。
```

D+3 复核条件测试：

```text

- 样本 8
- 大肉率 62.5%
- MFE20 均值 +30.09%

D+3 浮盈 >= 2%，且 D+1~D+3 板块至少 1 天仍在 Top15：
- 样本 4
- 大肉率 75.0%
- MFE20 均值 +50.21%

D+3 浮盈 >= 2%，且 D+2~D+3 主力/超大单都继续净流入：
- 样本 4
- 大肉率 100.0%
- MFE20 均值 +50.16%

仅看板块 D+1~D+3 仍进 Top15：
- 样本 10
- 大肉率 50.0%
- MFE20 均值 +28.49%

仅看 D+2~D+3 资金继续流入：
```

### 动态卖出特征验证

单项特征结论：

```text
1. 单纯价格回撤不能直接全卖。
   “盈利 >=8% 后回撤 5%”触发后，后 5 日仍有较高反弹概率，容易卖飞。

2. 超大单走弱比价格回撤更像风险信号。
   “累计超大单从峰值回撤 25% 且连续 2 天下降”触发较多，能压风险，但单独用会砍掉部分大票。

3. 主力 + 超大单连续 2 天净流出可以作为防守信号。
   它不适合单独做止盈，但适合和亏损、破位、板块退潮组合。

4. 板块退潮 + 跌破均线仍然有效。
   当前样本不支持删除这条规则。它更像“热点补涨失败/扩散结束”的退出信号。

5. 最优不是单一卖点，而是组合卖出。
```

当前组合动态卖出 v3：

```text
硬风控：
- 收盘亏损 <= -5%。

亏损 + 资金确认：
- 收盘亏损 <= -3%；
- 且主力/超大单连续 2 天同时净流出。

盈利后保护：
- 持仓期浮盈曾 >=8%；
- 从高点回撤 >=5%；
- 且超大单当天转负。

超大单撤退：
- 持仓期累计超大单从峰值回撤 >=40%；
- 且连续 2 天下降；
- 且当前收益 <5%。

板块扩散失败：
- 所属热点连续 2 天跌出 Top15；
- 且个股跌破 5 日线；
- 且当前收益 <5%。
```

动态卖出 v3 的意义：

```text
它不是为了最大化历史均值，而是为了把尾部亏损压下来。
在 D+1 尾盘主买点样本中：
- 不动态卖，Max20 观察均值 +7.55%，最差 -8.99%。
- 动态卖出 v3，均值 +5.65%，最差 -2.44%。

也就是说，它牺牲部分极端大肉，但显著降低尾部亏损。
```

当前操作框架：

```text

D+3：如果浮盈 >=2%，且板块或资金没熄火，升级为主仓/继续拿。
持仓后：不按天数卖，只按动态信号卖。

弱票处理：
D+3 未确认，且板块没延续、资金没继续，则后续一旦出现破均线、资金转负、板块退潮，应更敏感地退出。

强票处理：
D+3 已确认，尤其板块或资金仍延续，可以给更宽的盈利回撤空间，不要单纯因为价格回撤就全卖。
```

## 核心样本继续拆解：舒服赢家 / 痛苦赢家 / 失败样本

基于 332 个核心样本继续拆：

```text
舒服赢家：未来40日达到 +20%，且达到前最大浮亏不超过 8%。
痛苦赢家：未来40日达到 +20%，但达到前先亏超过 8%。
失败：未来40日没摸到 +10%，或40日收盘仍亏损。
中间：其余样本。
```

关键区别：

```text
1. 舒服赢家的 20 日位置更低，典型中位数 0.37。
2. 舒服赢家的量能更接近平量，典型中位数 0.96。
3. 痛苦赢家的 60 日乖离明显过大，典型中位数 13.85%，说明虽然能涨，但拿起来很折磨。
4. 失败样本不一定离60日线远，失败主要不是“均线太远”，而是低位/量能/后续板块延续组合不够好。
```

这次最重要结论：

```text
D+1 不回落单独看并不好。
但 “低位 + 量能正常 + D+1不回落 + 后续板块延续” 组合起来，有明显提升。
这说明 D+1 不是单独买点，而是二次确认；板块后续是否延续也很关键。
```

当前更合理的候选排序逻辑：

```text
第一层：必须是热门细分板块 + 个股低位 + 主力资金连续流入。
第二层：优先 20日位置 <=0.5。
第三层：优先量能比 0.8~1.1，其次 0.5~1.2。
第四层：规避 60日乖离明显过大，尤其 >10%~13%。
第五层：D+1 不回落只是确认，不是单独决定。
第六层：D+1~D+5 板块仍延续，是从普通候选升级为重点候选的重要条件。
```
