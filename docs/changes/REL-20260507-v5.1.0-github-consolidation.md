# REL-20260507 v5.1.0 GitHub 仓库收口发布说明

## 1. 发布结论
- 发布目标：先把本地完整状态收口到 `main` 并推送 GitHub。

- 版本号：`v5.1.0`。

## 2. 版本包含内容
1. 合入 GitHub `v5.0.10 ~ v5.0.20`：选股研究上下文、研究依据包、图表质量标记收口等。
2. 保留本地 `v5.1.0`：市场热点温度计、热点低位 L2 样本研究页与对应研究脚本。
3. 新增长期趋势选股档案：`docs/selection/long_term_trends/`。
4. 收口外部知识库同步源：`notebooklm-sync/` 只提交 Markdown 源，不提交生成 PDF。
5. 补充 Cloud Lite 边界：云端后续只保证盯盘 + 复盘。

## 3. GitHub 存档口径
- `main` 是本次收口后的长期主线。
- `v5.1.0` tag 作为 GitHub 侧版本锚点。
- 历史过程卡继续保留在 `docs/changes/`；旧 handoff 摘要进入 `docs/archive/`。

## 4. 云端发布前置条件
1. 先处理云端磁盘废数据，释放空间。
2. 验证 `/api/health`、盯盘接口、复盘接口正常。
3. 再发布 `v5.1.0` 到云端。
4. 发布后再做页面和 API 冒烟。

## 5. 风险说明
- 热点、选股、长期趋势研究默认是本地研究能力，不是 Cloud 必保能力。
- 云端旧数据清理只允许删除已确认废弃的备份/旧 sandbox，不删当前服务正在使用的正式库。
