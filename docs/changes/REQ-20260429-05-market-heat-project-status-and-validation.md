# 热门板块/板块热度项目阶段报告

## 目标

本项目不是为了用“板块热”直接买股票，而是验证：

```text
如果某只股票同时出现策略买点，并且处在真实热门细板块里，
是否能提高它成为未来强股的概率。
```

最终用途：

```text
板块热度 = 策略候选的过滤器 / 优先级排序器 / 仓位信心因子
```

## 当前数据周期

本地 atomic 日线数据覆盖：

```text
2025-01-02 ~ 2026-04-28
```

由于验证要求本地历史不少于 60 个交易日，所以近一年验证实际使用：

```text
2025-04-16 ~ 2026-04-28
约 250 个交易日
```

之前短周期验证：

```text
2026-01-20 ~ 2026-04-28
约 63 个交易日
```

## 已采纳的验证防呆

### 1. 不只看 Recall，也看 Precision

指标包括：

```text
Coverage：热门板块覆盖市场比例
Recall：未来强股命中热门板块比例
Lift：Recall / Coverage
Alpha：热门板块平均收益 - 全市场平均收益
Win Rate：热门板块胜率
```

### 2. 可交易性过滤

验证中已过滤：

```text
D 日成交额 < 3000 万
ST / *ST
本地历史不足 60 个交易日
D+1 一字涨停开盘买不到
```

### 3. 多标签污染控制

细颗粒热点命中时增加日内共振约束：

```text
股票 D 日上涨
且 板块 D 日上涨
```

### 4. 热点生命周期

不是死板连续上榜，而是滑动窗口：

```text
过去 5 个交易日内：
1 次上榜 = new_hot
2~3 次 = continuing_hot
4 次以上 = climax_hot
```

### 5. L2 龙头过滤与涨停豁免

已验证：

```text
热门细板块内 L2 净流入 Top20 / Top40
收盘封死涨停豁免 L2
微小板块保底选出至少 1 只：max(1, floor(N * pct))
```

## 当前判断

### 颗粒度是否合理？

当前细颗粒 Top15 口径基本合理：

```text
覆盖率稳定在 5% 左右
明显低于大主题 Top3 的 25%
能把热点范围压缩到更可研究的规模
```

所以“板块颗粒度”这一关已经完成第一版。

### 相关性是否足够？

要分两层看：

```text
强股命中相关性：够用
收益/胜率准确性：还不够强
```

证据：

```text
近一年 D+3 Lift 约 2.08
近一年 D+5 Lift 约 1.96
```

说明未来强股确实更容易来自细颗粒热点。

但：

```text
近一年 Alpha 为负
胜率低于全市场
```

说明即使进入热点池，也仍然有大量跟风和后排票拖累收益。

## 不应做的事

当前不能做：

```text
只因为股票属于热门板块就买入
只用热门板块做硬过滤
只用 L2 Top 分位杀掉非资金流入票
把 new_hot 直接当成 breakout 加分项
把 climax_hot 直接做一票否决
```

这些都会产生回测幻觉或误杀。

## 应该做的事

当前最合理用途：

```text
不要直接给策略信号提权。
先把细颗粒热点作为研究解释标签 / 风险提示标签。
```

候选票标记：

```text
fine_hotspot_hit
fine_hotspot_name
fine_hotspot_rank
fine_hotspot_stage
daily_resonance
l2_leader_flag
limit_up_core_flag
```

解释逻辑：

```text
策略信号 + 细颗粒热点 Top15 + 日内共振
=> 提示“题材热度参与”，但不自动加分

策略信号 + 热点池外
=> 不自动降级

热点内但 L2 弱
=> 不直接剔除，只提示资金不强

breakout 策略 + 热点共振
=> 重点检查是否已经处于高潮/追高

breakout 策略 + climax_hot
=> 强风险提示；进入影子排雷字段，但暂不直接一票否决

stealth 策略 + new_hot
=> 稀缺观察标签；只提示优先研究，不直接买入

breakout 策略 + 任意热点共振
=> 整体偏负，后续重点研究“是否已经过热/是否适合回避”
```

## 后续计划

```text
3. 把 stealth + new_hot 作为小样本机会字段继续滚动验证。
```

## 当前阶段结论

```text
板块颗粒度：第一版达标
强股相关性：存在，Lift 稳定 > 1
收益准确率：不足，Alpha 未稳定转正
L2 过滤：提高 Lift，但未改善长期 Alpha
策略共振 A/B：未通过，不应加权

实战定位：研究解释标签 / 风险提示标签，暂不做买入提权器
```
