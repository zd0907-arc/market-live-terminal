# REL-20260512-v5.1.4-market-heat-mainline-dashboard

## 结论

v5.1.4 是本地研究站市场热点温度计升级版：页面收口为“市场主线情报看板”，用细颗粒主题生命周期替代旧版热点排行，并补齐成分股微型 K 线和按日期刷新能力。

## 范围

- 保留：市场热点页顶部主线情报看板。
- 移除：旧版近 3 个月热门板块趋势、最近每日热门板块、热点排行和旧详情区。
- 新增：日期选择、热点缓存刷新、成分股微型 K 线卡片、点击成分股打开左侧单票详情。
- 新增：细颗粒板块 canonical 治理，去除完全重复和 Jaccard >= 0.90 的高度近重复主题。

## 6 池生命周期

| 池子 | 口径 |
|---|---|
| 今日最强 | 今日热度排名 Top5 |
| 首次新热 | 今日进 Top15；过去 20 日少热；近 5 日热度或排名明显抬升 |
| 主线再加速 | 今日进 Top10；近 20 日反复活跃 |
| 持续升温 | Top6~Top30；还不是成熟主线；近 5 日明显抬升 |
| 持续主线 | 今日仍在 Top30；近 20 日反复活跃 |
| 退潮观察 | 今日跌出 Top30；近期从前排明显掉队 |

阈值复核结论：

```text
Top5  = 当日最强
Top10 = 前排强热点
Top15 = 热区
Top30 = 观察边界
```

Top30 仍有统计意义，但不能单独等同强热点。

刷新入口：

- 页面按钮：`刷新最新数据`
- API：`POST /api/market_heat/fine_dashboard/refresh`

日期入口：

- API：`GET /api/market_heat/fine_dates`
- 日期选择器绿色线表示已有缓存，黄色点表示底层交易数据存在但热点缓存待生成。
