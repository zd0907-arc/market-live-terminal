# REL-20260507-v5.1.3-cloud-lite-production

## 结论
v5.1.3 是云端轻量生产发布版：云端默认只开放盯盘与复盘，选股、趋势研究、市场热点等研究类页面和 API 默认关闭。

## 范围
- 保留：`/` 盯盘首页、`/review` 正式复盘页。
- 屏蔽：`/selection-research`、`/trend-research`、`/market-heat`、`/market-heat/low-position-samples`。
- 云端 Docker 默认：
  - 前端 `VITE_CLOUD_LITE_MODE=true`
  - 后端 `ENABLE_RESEARCH_API_ROUTES=false`
- 本地 npm 开发默认仍是完整模式，不影响本地研究。

## 验证
- `npm run check:baseline`：147 个后端测试通过，前端构建通过。
- `VITE_CLOUD_LITE_MODE=true npm run build`：通过。
