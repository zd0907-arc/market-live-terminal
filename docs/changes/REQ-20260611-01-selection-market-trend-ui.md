## 2. 背景与目标
用户希望选股页不只给候选票，还能在实盘决策前快速看清近期市场环境水位，并且减少左侧导航区无效占高。本次发布同时覆盖前序 `8db6e7d` 的市场环境门控研究页、接口、研究产物，以及发布基线中暴露出的策略样本同源和临时库初始化问题。

核心目标：
- 把市场环境从纯数字压缩成可读的 90 日趋势图。
- 保留防守/观察/进攻判断和暂停新开仓建议。
- 支持鼠标悬停查看选中交易日的水位与状态。
- 压缩左侧导航，把日期、策略状态、候选分类收进一行。

## 3. 方案与边界
- 做什么：
  - 新增市场环境门控研究页与选股市场环境接口，用于解释市场水位、来源表现和门控研究结论。
  - 选股页左侧新增“近期市场趋势”90 日水位图。
  - 趋势图铺满水位区域，文字作为轻量覆盖信息。
  - 悬停图中任意位置时，吸附最近交易日并展示日期、水位、市场状态。
  - 弱势证据收进标题后的感叹号 hover 说明。
  - 删除“今日候选处理图”、独立“股票导航”标题和说明句。
  - 将日期、策略状态、`全部/买点/观察/拦截/持仓/卖出/可操作` 分类整合为单行。
  - 资金流回调稳健、趋势中继高质量回踩在研究样本覆盖期优先读取固化研究样本，保证候选、画像和评估数字同源。
  - L2 历史库、选股研究库的 schema 初始化缓存改为按 DB 路径记录，避免测试/临时库切换后漏建表。
- 不做什么：
  - 不改变市场环境水位计算口径。
  - 不改变候选排序、买卖点、策略输出和实盘决策逻辑。
  - 不把系统建议升级为自动交易指令。

## 5. 验收标准
- Given：访问 `http://127.0.0.1:3001/selection-research`，选择 `2026-06-10` 并查看候选。
- When：页面加载完成。
- Then：左侧显示“近期市场趋势”，90 日曲线铺满区域，当前状态显示 `防守持续下跌 · 90日水位走低`。
- Then：页面不再显示独立“股票导航”标题，也不显示“左侧扫走势，点击卡片后右侧查看单票详情。”说明句。
- Then：鼠标悬停在趋势图上，显示对应交易日日期、水位分数和市场状态。
- Then：`/api/selection/daily-candidates?date=2026-06-10&include_exit_watchlist=true` 返回 `market_environment.recent.length = 90`。
- Then：`/api/selection/market-environment`、`/api/selection/market-environment/backtest-summary`、`/api/selection/market-environment/source-regime-summary` 可返回市场环境研究数据。

## 6. 风险与回滚
- 风险：
  - 悬停浮层是 SVG 内部轻量实现，只适合当前水位图，不是通用图表 tooltip。
  - 生产 NAS 若未同步最新 `research/current` 或 selection DB，页面仍可能无候选或无趋势数据。
  - S01/S02 在历史研究样本覆盖期优先使用固化研究样本；样本外仍回落动态计算，因此不能把历史高胜率外推为当前市场必然有效。
- 回滚：
  - Git 回滚 `v5.2.17` 对应提交并重新部署 NAS。
  - 若只需临时恢复布局，可回滚 `src/components/selection/SelectionResearchPage.tsx` 的本次改动。
