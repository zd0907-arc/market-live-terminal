# 通信线缆及配套：2026 年启动根因复盘

## 结论

从 2026 年 1 月底视角看，这波不是季报驱动。真正的早期驱动是：

```text
海外 AI 算力资本开支上修
+ 800G / 1.6T / CPO / 硅光 / OCS 等光互连预期升温
+ 光纤光缆供需偏紧与涨价预期
+ A 股资金从光模块/CPO前排向光纤光缆扩散
```

季报是一季度末、4 月下旬才出来的确认项，不是 1 月启动项。

## 事前能不能知道谁是龙头？

不能一次性知道，但可以按阶段提高确定性。

| 阶段 | 当时能判断什么 |
| --- | --- |
| 1 月上旬 | 只能知道光通信/CPO/光互连是 AI 算力扩散方向，还不能确定光纤光缆哪只最强。 |
| 1 月 19-28 日 | 亨通、中天先突破，说明板块中军开始动；长飞、通鼎随后突破，说明弹性票开始接力。 |
| 2 月中旬 | 长飞、通鼎短期弹性明显强于中军，长飞进入龙头候选。 |
| 3 月底 | 长飞二波继续大涨，强度显著领先，龙头身份基本确认。 |
| 4 月下旬 | 长飞/亨通/中天季报验证，长飞利润弹性最强，龙头逻辑闭环。 |

## 这波是不是业绩驱动？

分阶段看。

```text
1 月启动：不是季报驱动，是行业预期和消息面驱动。
2-3 月主升：行业预期 + 资金趋势强化。
4 月确认：季报/年报把前排逻辑坐实。
```

所以不能说“这波是季报驱动”。更准确是：

```text
先炒 AI 光互连和光纤涨价预期；
后由长飞、亨通、中天的一季报确认。
```

## 对后续板块研究的启发

1. 早期要找“产业逻辑 + 中军先动”，不是等财报。
2. 龙头不是最早涨的，而是涨完还能二波新高，并且财报能确认。
3. 弹性票和业绩龙头要分开：通鼎涨得猛，但不是业绩龙头。
4. 后排脉冲票不能按龙头逻辑持有。
5. 如果板块 4 月已经季报确认，后面再买就不能用“启动逻辑”，要用“回调后二波/补涨逻辑”。
