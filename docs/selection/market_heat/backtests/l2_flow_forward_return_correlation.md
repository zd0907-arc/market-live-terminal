# L2 资金流与未来收益相关性分析

结论：在前面筛出来的候选样本里，L2 净流入单因子没有明显正向预测力；最强关系反而是弱负相关，尤其是 20 日超大单/合计净流入占成交额越高，后 5 日收益越低。

## 样本口径

- 原始候选：`3077` 个 symbol-date。
- 可计算样本：`3077`。
- 剔除未来收益绝对值 > 60% 的异常样本后：`3072`。
- 因子：截至 signal_date，当日及以前近 3/5/10/20 日 L2 主力、超大单、合计净流入。
- 同时计算绝对净流入 `*_yi` 和净流入 / 同期成交额 `*_amount_ratio`。
- 额外计算资金边际变化：`3d_vs_10d`、`5d_vs_20d`，用于观察短期资金是否刚转强。
- 目标：signal_date 收盘到后 1/3/5/10 个交易日收盘收益。

## 初步判断

1. 相关性整体偏弱，说明 L2 不能单独决定买入。
2. 绝对资金强度不是好买点，长窗资金占比越高，越可能代表已经被资金做过一轮。
3. 后续更应该测“低位 + 资金边际改善”，而不是简单追主力/超大单净流入最大。
4. 下一版入场过滤应改成：主题先动 + 个股未大涨 + 价格位置低 + 近3/5日资金从负转正或短窗强于长窗。
