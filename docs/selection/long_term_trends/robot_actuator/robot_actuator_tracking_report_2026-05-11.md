# 机器人执行器/减速器长期趋势跟踪日报（2026-05-11）
## 1. 当前系统判断
- 行业趋势分：63/100，观察加强 / 未到强趋势。
- A股可操作分：45.0/100，研究13家，只让5家进入观察池。
- 当前结论：值得跟踪，不值得直接追买。4月以来本地热点反复出现，Tesla量产窗口临近，执行器/减速器是硬件链核心。但本页先拆分支和公司利润路径，只把验证路径直接的公司放进观察池。
- 卡住原因：最大卡点不是方向，而是从样机到批量订单的验证不足；A股纯标的利润基数小、估值和价格弹性都偏高。
- 下一触发：机器人执行器/减速器连续进入Top30，Tesla Fremont按7月底/8月启动，三花/双环/绿的/丝杠链披露订单或中报收入验证。
- 阶段：概率上升 / 预警期；下一阶段：订单 / 量产验证期。

## 9. 买入/加仓/降级条件
- 买入观察线：海外量产实际启动 + 国内核心部件订单披露 + 核心A股分歧后守位转强 + 中报机器人相关收入或毛利率改善。
- 加仓线：行业分升到75以上，且A股可操作分升到60以上；必须由订单/收入/价格承接三者共同触发。
- 降级线：Tesla量产延期或产量极慢、热点连续两周退出Top50、公司公告仍停留在样机验证、核心标的利好不涨并跌破关键位。
