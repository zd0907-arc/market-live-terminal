# 长期趋势仓位与持有规则

## 1. 仓位的本质

分仓不是因为用户扛不住波动。用户已经证明能承受较大回撤。

分仓真正解决的是：

- 防止单一判断错误毁掉整个账户；
- 避免总资产暴利回吐造成心理压力；
- 防止满仓后没有能力跟踪其他主线；
- 防止卖飞后因为原价格锚定而不敢重新进入；
- 给逻辑升级留出加仓和重估空间。

## 2. 建议账户结构

不要求过度分散。适合用户的是少数高认知仓：

```text
长期趋势主仓：60%-70%
中短线/资金跟随仓：20%-30%
试错/线索验证仓：10%
```

长期趋势主仓内部建议：

- 1 条最强主线：30%-50%；
- 1-2 条次强主线：各 10%-20%；
- 单一股票极限仓位：原则上不超过 50%-60%，除非逻辑、估值、风险出口都极清楚。

## 3. 单票仓位分层

```text
观察仓：5%-10%
研究确认仓：15%-25%
主仓：30%-50%
极限重仓：50%-70%，仅限极高确定性
满仓单票：非常规状态，必须有明确退出和复盘纪律
```

## 4. 买入后如何升级仓位

### 可以加仓的情况

- 产业趋势继续变强；
- 公司财报验证逻辑；
- 盈利预测上修；
- 板块内相对强度提升；
- 回调不破长期趋势；
- 新逻辑出现，并能提高合理估值。

### 不该加仓的情况

- 只是因为跌了想摊低成本；
- 原逻辑没有验证；
- 只靠消息刺激；
- 估值已经极端，但盈利没有跟上；
- 自己只是因为卖飞焦虑想追回。

## 5. 到目标价之后怎么办

目标价不是清仓点，而是重估点。

当股价到达原目标价/目标市值时，执行四问：

1. 原逻辑是否已经兑现？
2. 有没有新逻辑出现？
3. 新逻辑能否上修盈利或估值倍数？
4. 如果现在没有持仓，我是否还愿意买入一部分？

对应动作：

| 判断 | 动作 |
| --- | --- |
| 原逻辑兑现，无新逻辑 | 分批退出 |
| 原逻辑兑现一部分，但趋势仍强 | 减仓，不清仓 |
| 新逻辑出现，估值需要上修 | 保留底仓，重新估值 |
| 看不懂但趋势没坏 | 降仓到可承受仓位 |
| 逻辑证伪 | 卖出 |

## 6. 利通电子案例规则化

用户当时 25 元以下成本，43 元附近清仓，原因是原目标市值约 120 亿已达到。

以后遇到类似情况：

- 可以在目标市值附近卖出 30%-50%，锁定收益；
- 不应一刀清仓；
- 剩余 20%-30% 作为趋势底仓；
- 若后续出现 AI 主线加强、利润大涨、板块重估，应重新估值；
- 如果卖飞后重新进入，只能按新逻辑和新风控买，不能用原卖出价做心理锚。

## 7. 卖出规则

长期趋势票卖出依据：

- 产业逻辑证伪；
- 财报低于核心假设；
- 商品价格/订单/销量等关键指标反转；
- 盈利预测下修；
- 板块主线明显退潮；
- 周线趋势破坏且反抽失败；
- 估值极端透支，同时价格和资金出现背离。

不应单独因为以下原因清仓：

- 已经翻倍；
- 达到最初目标价；
- 短期回撤；
- 担心利润回吐；
- 卖掉后想等跌回来。

## 8. 重新买回规则

卖飞后如果想重新进入，禁止问：

> 它会不会跌回我卖出的价格？

应该问：

> 按现在的新信息、新利润、新估值和新趋势，它现在还值不值得买？

重新买回可以先用 5%-10% 观察仓，避免心理锚导致完全错过。
