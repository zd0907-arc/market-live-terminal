# 长期趋势选股总框架

## 1. 一句话原则

长期趋势选股的核心不是预测短期涨跌，而是判断：

> 一个产业变量是否会持续 1-3 年改变企业利润，且当前股价还没有完全反映。

## 2. 长期趋势票的四个条件

### 1. 大趋势

必须处在真实产业变化中，例如：

- AI 算力、存储、光模块、服务器、液冷；
- 国产替代；
- 供需反转和涨价周期；
- 新能源/机器人/智能汽车；
- 军工、低空经济、医药创新等政策和产业共振方向。

只靠短期概念热度，不算长期趋势。

### 2. 强传导

生活现象或宏观变化必须能传导到公司利润表：

- 收入增长；
- 毛利率提升；
- 存货重估；
- 订单增加；
- 产能释放；
- 费用率下降；
- 盈利预测上修。

不能只停留在“这个概念很火”。

### 3. 核心受益者

优先找：

- 业务纯度高；
- 弹性大；
- 行业地位清楚；
- 财报能验证；
- 股价能代表该主线的标的。

少碰：

- 概念蹭边；
- 收入占比很低；
- 利润不敏感；
- 只靠消息刺激的公司。

### 4. 可跟踪验证

每只长期票都必须有下一次验证点：

- 季报/年报；
- 产品价格；
- 出货量/销量；
- 订单/合同；
- 产能爬坡；
- 机构盈利预测；
- 板块相对强度。

没有验证点，就不能重仓长期持有。

## 3. 长期趋势研究流水线

```text
生活/市场线索
  ↓
产业变量识别
  ↓
产业链拆解
  ↓
A股/港股/美股标的映射
  ↓
财务弹性判断
  ↓
估值区间粗算
  ↓
价格和资金确认
  ↓
建观察仓/研究仓/主仓
  ↓
按验证点复盘
  ↓
逻辑升级则上修估值，逻辑证伪则退出
```

## 4. 长期趋势票和短线热点票的区别

| 维度 | 短线/中线热点 | 长期趋势 |
| --- | --- | --- |
| 核心问题 | 现在资金追什么 | 未来 1-3 年利润是否重构 |
| 数据重点 | 资金、热度、涨停、L2 | 产业、财报、价格、订单、估值 |
| 持有周期 | 几天到几周 | 几个月到几年 |
| 卖出依据 | 冲高、资金转弱、回撤 | 逻辑证伪、估值极端、趋势破坏 |
| 项目模块 | market_heat / selection_research | long_term_trends |

## 5. 研究时优先问的 8 个问题

1. 这个现象是不是足够大？
2. 它是一次性事件，还是 1-3 年趋势？
3. 产业链里谁最赚钱？
4. A 股有没有足够纯的表达？
5. 利润弹性来自收入、毛利率、库存、订单还是估值重估？
6. 当前股价反映了几成？
7. 下一次验证点是什么？
8. 什么情况说明我错了？

## 6. 估值原则

不要只用静态目标市值作为卖点。

目标市值到达后，应进入“重估点”：

- 原逻辑是否已经完全兑现？
- 新逻辑是否出现？
- 盈利预测是否上修？
- 市场是否开始给更高估值体系？
- 公司是否从普通反弹票升级为产业核心票？

如果逻辑升级，应重新估值，而不是机械清仓。
