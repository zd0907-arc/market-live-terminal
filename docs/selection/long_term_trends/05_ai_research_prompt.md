# 长期趋势选股 AI 对话上下文与提问模板

## 1. 使用方式

以后用户来讨论一个投资线索时，可以先让 AI 阅读本文件，或者直接复制“固定上下文”。

AI 的任务不是直接给买卖建议，而是帮助用户完成：

- 线索拆解；
- 产业链映射；
- 标的筛选；
- 财务和估值验证；
- 持仓/观察计划；
- 证伪条件设计。

## 2. 固定上下文

```text
我在 market-live-terminal 项目里做长期趋势选股研究。

我的背景：
- 我主要投资中国 A 股，也会关注港股/美股。
- 我从 2024 年 9 月牛市起点附近入市，目前总收益约 40%。
- 我不缺波动承受力，曾经全仓单票扛过约 35% 回撤。
- 我买过一些后来大涨的股票，但没拿住，例如金海通、海光信息、利通电子。
- 利通电子是典型案例：我 25 元以下成本全仓持有，35 附近卖出约四分之一，40 附近继续卖，43 附近清仓；当时按约 120 亿市值作为估值锚。后面它因为 AI 方向、利润大涨、市场重估继续涨到 160 附近。
- 我的核心问题不是完全选不到，而是：生活中能感知产业信号，但缺少把线索转成投资研究的 SOP；买到强票后，缺少逻辑升级后的重新估值和继续持有机制。

你接下来要帮我做的事：
- 不要直接喊买卖。
- 先判断这个线索是不是长期趋势，而不是短线热点。
- 帮我画产业链传导。
- 找最核心受益环节和 A 股/港股/美股表达。
- 帮我判断利润弹性来自哪里。
- 给出需要验证的数据和下一步研究清单。
- 如果涉及持仓，帮我区分：观察仓、研究仓、主仓、减仓、清仓、重新估值。
- 卖出逻辑必须基于产业/财务/趋势证伪，而不是单纯涨幅。
```

## 3. 线索研究提问模板

```text
我观察到一个现象：{现象}
来源：{小红书/新闻/同事/生活观察/财报/价格数据}
我初步理解：{自己的理解}
可能相关行业：{行业}

请按长期趋势选股框架帮我分析：
1. 这是一时热点，还是可能持续 1-3 年的产业趋势？
2. 背后的核心驱动是需求增长、供给收缩、涨价、政策、技术替代，还是其他？
3. 产业链怎么传导？上游、中游、下游谁最受益？
4. A 股/港股/美股有哪些高纯度标的？请按业务纯度和利润弹性排序。
5. 这些公司的利润弹性分别来自收入、毛利率、库存、订单、产能还是估值重估？
6. 当前需要看哪些财务指标和行业数据？
7. 哪些信号出现时可以从观察进入研究仓？
8. 哪些信号说明逻辑被证伪？
9. 如果已经涨很多，应该如何重新估值，而不是简单因为涨幅卖出？
```

## 4. 个股重估提问模板

```text
我持有/关注的股票是：{股票}
买入成本/关注价格：{价格}
当前价格：{价格}
当前涨幅：{涨幅}
原始买入逻辑：{逻辑}
原始目标市值/目标价：{目标}
最新出现的新信息：{财报/订单/涨价/产业变化/资金/板块变化}

请帮我判断：
1. 原始逻辑是否已经兑现？
2. 有没有新逻辑出现？
3. 新逻辑是否足以提高目标市值或估值倍数？
4. 如果现在没有持仓，还值不值得买观察仓？
5. 应该清仓、减仓、保留底仓，还是重新估值？
6. 接下来最重要的 3 个验证点是什么？
7. 什么情况说明我应该退出？
```

## 5. 卖飞后重新进入提问模板

```text
我之前卖飞了一只股票：{股票}
卖出价格：{价格}
当前价格：{价格}
卖出原因：{原因}
后续上涨原因：{自己理解}
我现在不敢买回，因为锚定之前卖出价。

请不要安慰我，也不要直接建议追高。请帮我重新建模：
1. 这只票现在和我卖出时相比，核心变量发生了什么变化？
2. 当前价格是否对应了更高的盈利预期或估值体系？
3. 如果完全忘记我的卖出价，现在是否值得进入观察仓？
4. 如果买，只能买多少仓位，证伪点是什么？
5. 如果不买，应该跟踪哪些信号等待下一次机会？
```
## 6. 输出规则

长期趋势研究时，AI 必须先在对话里给出完整核心结论、关键证据、判断和下一步动作。文档只是额外归档，不能用“已写入文档”替代正文回答。除非用户明确只要求落档，否则不要让用户必须打开文档才能看到研究结果。
