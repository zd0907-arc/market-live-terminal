# 长期趋势选股档案

> 定位：把生活线索、产业认知、财务验证和长期持仓纪律沉淀成一套研究系统。它不是短线资金跟随模块，也不是自动交易模块。

## 1. 为什么要建这个档案

当前项目里的选股研究主要偏：

- 热点主题；
- 资金确认；
- 强者恒强；
- 5-20 个交易日窗口；
- 买点、卖点和回测。

这些适合中短期交易，但不能解决一个更重要的问题：

> 当自己提前看到一个产业趋势、甚至已经买到一只大牛股时，怎样把它研究清楚、拿得住、在逻辑升级时重新估值，而不是因为涨幅满意就提前清仓。

本档案专门服务长期趋势选股。

## 2. 用户当前投资画像

- 当前主要投资市场：中国 A 股，偶尔关注港股/美股。
- 入市时间：2024 年 9 月牛市起点附近。
- 截至当前自述总收益约 40%。
- 有较强波动承受能力，曾经全仓单票扛过约 35% 回撤。
- 已经真实买过并卖飞过若干大趋势/大涨幅股票：
  - 金海通：约 80-90 元买过，后续涨至 200 元以上。
  - 海光信息：约 130 元买过，后续涨至 300 元附近/以上。
  - 利通电子：25 元以下成本，全仓持有，35 附近卖出约 1/4，40 附近继续卖，43 清仓；后续最高涨至 160 附近。
- 关键痛点：不是完全选不到，而是缺少“趋势升级后的重新研究和继续持有机制”。
- 生活线索敏感度较强：例如较早从小红书感知内存/SSD 涨价，从身边场景感知小米汽车热度，但没有形成固定的投资研究转化流程。

## 3. 核心结论

长期趋势选股不是问：

> 这只股票涨了一倍，要不要卖？

而是问：

> 涨了一倍之后，支撑它继续上涨的产业变量、利润变量、估值变量有没有变强？

如果变量变强，应该重新估值，至少保留趋势底仓。
如果变量兑现但没有升级，可以分批退出。
如果逻辑被证伪，应卖出。
如果看不懂，应该降仓，而不是在情绪驱动下一刀清仓。

## 5. 和现有模块的关系

- 现有短线/中线模块：解决“市场现在热什么、资金追什么、什么时候冲高卖”。
- 长期趋势模块：解决“哪个产业趋势可能持续 1-3 年，谁是最核心受益者，涨了以后还能不能继续拿”。

两者不能混用卖点。短线票可以按资金和 5-20 日窗口卖；长期票必须按产业逻辑、财务兑现、趋势破坏和估值透支来卖。
