# 深度研究工作流：从生活现象到长期趋势选股

> 目的：解决“我看到一个现象之后，接下来到底怎么研究到可以决策”的问题。

## 1. 第一版为什么不够

机会卡只能回答：

- 这件事可能重要；
- 大概相关哪些产业；
- 可以先关注哪些股票。

但它不能回答：

- 这个趋势到底能持续多久；
- 谁的利润真的会变；
- 当前股价反映了几成；
- 现在是启动、主升、高潮，还是见顶；
- 应该观察、小仓、主仓，还是放弃。

所以长期趋势研究必须进入“证据链”层。

## 2. 深度研究的 6 层结构

### L0：现象记录

只记录，不判断。

```text
我看到了什么？
它在哪里发生？
是个例，还是多处同时出现？
为什么我觉得异常？
```

### L1：因果假设

把生活现象转成可验证假设。

```text
现象：消费级 SSD/内存涨价。
假设：AI 数据中心需求挤占存储产能，导致企业级和消费级存储共同涨价。
```

要求：必须写成“如果 A，那么 B，因此 C 公司利润会变化”。

### L2：产业证据

证明这不是散户臆想。

至少找 3 类证据：

1. 需求端：订单、出货、CapEx、渗透率、用户增长。
2. 供给端：产能、库存、扩产周期、供给瓶颈。
3. 价格端：产品报价、合约价、现货价、毛利率。

没有价格或订单证据的，只能叫故事，不能叫趋势。

### L3：产业链利润传导

把“行业好”拆成“谁赚钱”。

必须回答：

- 上游、中游、下游分别是谁？
- 哪个环节议价权最强？
- 哪个环节利润率改善最大？
- 哪个环节只是收入变大但利润不一定变好？
- A 股公司到底在哪一环？

### L4：公司横评

不能只看一个票，必须横向比较。

最少比较 5 项：

| 维度 | 要看什么 |
| --- | --- |
| 业务纯度 | 收入里有多少真正来自该趋势 |
| 利润弹性 | 收入、毛利率、库存、订单哪个变量变强 |
| 财务质量 | 毛利率、经营现金流、存货、合同负债 |
| 估值位置 | 按保守/中性/乐观利润算当前贵不贵 |
| 交易状态 | 是否已经高潮，资金是否派发，龙头是否抗跌 |

### L5：行动门槛

研究最后必须输出动作，但动作不是“买/卖”二元，而是：

```text
放弃
继续观察
建 5%-10% 观察仓
进入 15%-25% 研究仓
升级主仓
只持有不加仓
减仓但保留底仓
清仓
```

每个动作必须绑定触发条件。

## 3. 证据等级

| 等级 | 证据 | 权重 |
| --- | --- | --- |
| S | 财报兑现、产品价格持续上涨、订单/合同、行业权威数据 | 最高 |
| A | 龙头公司公告、客户 CapEx、机构盈利预测上修 | 高 |
| B | 板块趋势、资金流、ETF 放量、研报逻辑 | 中 |
| C | 社媒热度、生活观察、新闻情绪 | 低 |

生活观察只能触发研究，不能直接触发重仓。

## 4. 趋势阶段判断

| 阶段 | 特征 | 动作 |
| --- | --- | --- |
| 0. 线索期 | 生活现象出现，股价没反应 | 建线索卡 |
| 1. 预期差期 | 少数龙头开始走强，市场没完全理解 | 深挖，可观察仓 |
| 2. 财报验证期 | 利润开始爆，机构上修 | 可研究仓/主仓 |
| 3. 一致加速期 | ETF、后排、新闻全面爆发 | 不追高，等分歧 |
| 4. 分歧再确认期 | 高位回调后龙头抗跌并继续新高 | 决定是否升级/继续持有 |
| 5. 退潮期 | 利好不涨，资金派发，财报低预期 | 降级/退出 |

## 5. 研究输出必须包含的 5 个表

每条长期趋势，最终至少要有：

1. 产业链传导表。
2. 需求/供给/价格证据表。
3. 标的横评表。
4. 估值情景表。
5. 行动触发表。

缺任何一个，都还只是初步研究。

## 6. 最小决策标准

一条线能进入长期趋势池，至少满足：

- 有真实产业变量，不只是概念；
- 有价格、订单或财报证据之一；
- 有 3 个以上可比较标的；
- 能明确谁是核心受益者；
- 能写出证伪条件；
- 能判断当前处于哪个交易阶段。
