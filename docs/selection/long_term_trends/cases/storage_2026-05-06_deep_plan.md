# 存储涨价深度研究计划（2026-05-06）

> 本文件不是结论稿，而是把“存储主线”从浅层机会卡推进到可决策研究所需的数据清单和判断框架。

## 1. 研究问题

当前要回答的不是“存储是不是好方向”，而是四个更硬的问题：

1. AI 存储需求是 1-3 年趋势，还是 2026Q2/Q3 的价格周期？
2. A 股存储链的利润是结构性提升，还是低成本库存带来的一次性暴利？
3. 2026-05-06 的市场状态是主升开始、主升中继，还是一致性高潮？
4. 如果不追高，下一次可参与的验证信号是什么？

## 2. 核心假设

### 假设 A：AI 确实带来长期存储需求

证据方向：

- NVIDIA GPUDirect Storage 说明 AI/HPC 工作负载存在 GPU 与存储之间的数据通路瓶颈，存储已经不是普通外设，而是 AI 计算管线的一部分。
- NVIDIA AI Data Platform 把企业存储和 AI query agents 结合，说明企业数据/存储系统正在被 AI 化。
- SNIA 设立 Storage.AI，说明行业开始把 AI 存储作为标准化问题处理。
- Seagate 调研显示，AI 应用会推动云存储需求显著增长。

判断：长期需求成立，但这只能证明产业方向，不等于 A 股任意存储票都便宜。

### 假设 B：2026 年存储价格仍在上行

证据方向：

- DRAM/NAND 合约价；
- Enterprise SSD 订单和短缺；
- HBM 产能挤占 conventional DRAM；
- 云厂商 CapEx 上修。

判断：如果 Q3 价格继续上修，主线未结束；如果 Q3 价格见顶，A 股模组厂估值要降级。

### 假设 C：A 股利润弹性主要来自库存价差和产品结构

需要验证：

- Q1 毛利率是否异常高；
- 高毛利是否可复制到 Q2/Q3；
- 存货是否继续增加；
- 合同负债/订单是否同步增加；
- 经营现金流是否改善。

如果只有存货涨、现金流差、合同负债不跟，风险上升。

## 5. 当前阶段判断

截至 2026-05-06，暂定为：

```text
产业阶段：价格上行 + 财报验证期。
交易阶段：一致加速期。
```

含义：

- 不应该因为今天涨得多就否定产业；
- 也不应该因为产业好就在高潮日追主仓；
- 真正的机会在“分歧后仍强”的龙头，而不是当天所有涨停股。

## 6. 下一步验证计划

### 未来 1-5 个交易日

看交易强弱：

- 涨停核心票次日是否继续强；
- 高开后是否放量回落；
- 龙头和后排是否分化；
- L2 是否连续净流入；
- ETF 是否高潮后杀溢价。

输出：短期是否进入可观察仓。

### 未来 2-4 周

看产业确认：

- 是否有更多存储价格上修；
- 是否有公司 Q2 预告；
- 是否有机构盈利预测继续上修；
- 是否出现新的 CSP/AI server 订单数据。

输出：长期趋势是否继续升级。

### Q2 预告/中报后

看财报硬验证：

- 毛利率是否维持高位；
- 存货是否健康；
- 合同负债是否增加；
- 经营现金流是否改善；
- 市场是否愿意按全年利润重估。

输出：能不能从研究池进入主仓候选。

## 7. 行动触发表

| 情况 | 判断 | 动作 |
| --- | --- | --- |
| 分歧后龙头不跌，L2 连续转正 | 趋势强 | 可观察仓 |
| Q2 预告继续超预期，毛利率高于市场担忧 | 财报验证 | 可研究仓 |
| Q3 价格继续上修，龙头创新高 | 主线未结束 | 继续持有/考虑升级 |
| 高位放量滞涨，L2 连续流出 | 一致性退潮 | 不追，降级 |
| Q2 毛利率明显回落，存货继续高增 | 利润质量变差 | 降级/退出 |
| 价格数据开始下修 | 产业证伪 | 主线降级 |

## 8. 这条线最需要补的研究

1. 全球原厂：三星、SK 海力士、美光到底谁在扩产，扩什么。
2. A 股公司：利润中有多少是库存价差，多少是长期订单。
3. 企业级 SSD：A 股公司到底有没有真实客户和项目。
4. 估值：用 50/80/110/140 亿利润情景重新算德明利、江波龙、佰维存储。
5. 交易：跟踪 2026-05-06 后 5 日龙头/后排分化。
