# 厄尔尼诺历史影响与行业传导研究（2026-05-09）

> 目的：从“厄尔尼诺会影响很多东西”的泛泛判断，推进到“历史上哪些商品更容易受影响、怎么传导到行业和股票”的研究框架。

## 1. 先解释 RU 和 NR

### RU 是什么

RU 是上海期货交易所的 **天然橡胶期货**。

通俗理解：

```text
RU = 国内天然橡胶期货主品种
价格单位 = 元/吨
看的是国内天然橡胶市场预期
```

网页上看到的“橡胶主连 / RUM”，就是把当前最活跃的 RU 合约连续拼起来，方便看趋势。

### NR 是什么

NR 是上海国际能源交易中心的 **20号胶期货**。

通俗理解：

```text
NR = 20号胶期货
20号胶 = 国际轮胎工业常用天然橡胶原料
价格单位 = 元/吨
更贴近东南亚进口胶、轮胎原料和国际贸易
```

### 主力是什么意思

期货不是只有一个合约，而是按月份交易，例如 RU2609、NR2607。

```text
主力合约 = 当前成交量 / 持仓量最大、流动性最好的那个月份合约
主连 = 把每一段时间的主力合约拼起来，形成连续价格图
```

所以：

- RU 主力：看国内天然橡胶期货最活跃合约。
- NR 主力：看 20号胶最活跃合约。
- RU-NR 价差：看国内全乳胶/交割体系相对国际 20号胶的强弱。


## 4. 厄尔尼诺对行业和股票的传导

### 4.1 商品价格传导

```text
厄尔尼诺
  ↓
区域天气异常
  ↓
产量 / 割胶 / 收成 / 出口扰动
  ↓
商品价格上涨
  ↓
上游资源或种植公司受益
  ↓
下游加工公司成本承压，除非能提价
```

### 4.2 股价为什么会动

股价不是因为“厄尔尼诺”四个字动，而是因为市场预期这几类变量变：

1. 产品价格上涨。
2. 公司库存升值。
3. 毛利率改善。
4. 订单或政策项目增加。
5. 下游提价或成本压力变化。
6. 市场给主题估值溢价。

### 4.3 哪些最容易从天气走到股票

| 链条 | 商品/变量 | 股票映射 | 研究优先级 |
| --- | --- | --- | --- |
| 橡胶 | RU/NR、库存、割胶天气 | 海南橡胶；轮胎股反向观察 | 高 |
| 棕榈油/油脂 | 棕榈油、豆油、菜油 | 国内 A 股映射不纯，更多是期货/油脂链 | 中 |
| 粮食/种业 | 玉米、小麦、稻米 | 隆平高科、登海种业、荃银高科 | 中 |
| 水利抗旱 | 干旱、招投标 | 大禹节水 | 中 |
| 农资 | 化肥、农药需求 | 云天化、亚钾国际、新洋丰、扬农化工 | 中 |
| 高温制冷 | 空调出货、电力负荷 | 美的、格力、三花 | 低到中，偏高温链 |

## 5. 现在研究方法要调整

之前厄尔尼诺研究确实偏泛。后续不能再把很多公司简单堆进观察池。

新的推进顺序：

1. **先做商品**：橡胶、棕榈油、粮食、糖、咖啡/可可。
2. **再做传导**：上游受益，还是下游成本压力。
3. **再做股票**：只给有利润传导的公司建卡。
4. **最后才谈操作**：价格确认、财报确认、位置确认。

## 6. 橡胶分支下一步

橡胶先按独立主线推进，优先级高于其他厄尔尼诺分支。

已接入跟踪：

- RU 主连；
- NR 主连；
- RU-NR 价差；
- 2024 以来价格阶段；
- 长周期 RSS3 / TSR20；
- 六因子驱动框架。

待补：

1. 库存 / 仓单。
2. 泰国、印尼、海南降雨和割胶。
3. 轮胎开工率。
4. 原油、丁二烯、合成橡胶。
5. 海南橡胶利润弹性。

## 7. 结论

当前我会把厄尔尼诺主题收敛成三个优先研究分支：

```text
第一优先：橡胶
第二优先：棕榈油 / 油脂
第三优先：粮食种业 / 水利抗旱
```

股票层面现在只允许：

- 海南橡胶进入 A 类核心观察；
- 大禹节水、隆平高科进入 B+/A- 观察；
- 轮胎股只做成本压力观察；
- 其他公司暂时不做操作依据。
