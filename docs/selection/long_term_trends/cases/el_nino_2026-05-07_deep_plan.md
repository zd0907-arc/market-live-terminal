## 2. Step 0：线索入库

原始线索：

```text
厄尔尼诺今年可能发生；橡胶也可能受影响。
```

初始假设：

```text
如果 2026 年中后段进入并维持厄尔尼诺状态，
那么全球降雨和温度异常可能扰动农业、橡胶、水资源和电力负荷，
因此部分上游资源/农资/水利公司可能出现价格、订单或利润变化。
```

当前状态：

```text
观察期前置；不能直接进入交易确认。
```

## 3. Step 1：真假和概率核验

| 问题 | 当前答案 | 证据等级 |
| --- | --- | --- |
| 现在是否已发生 | 尚未确认。NOAA/CPC 当前仍说 ENSO-neutral。 | S |
| 今年是否必然发生 | 不是必然，是高概率预测。 | S |
| 概率何时最高 | 2026 年中后段，尤其 10-12 月概率更高。 | S |
| 中国口径 | 预计 5 月进入状态，夏秋季可能形成中等及以上强度事件。 | A |
| 事件确认标准 | 需要海温距平持续达标，不能只看单月。 | S |

结论：

```text
“必然发生”降级为“高概率发生”；
“进入状态”不等于“事件确认”；
“事件确认”不等于“投资确认”。
```

## 4. Step 2：市场讨论扫描

已扫到的市场联想：

| 方向 | 评论/概念常见联想 | 初步处理 |
| --- | --- | --- |
| 橡胶 | 海南橡胶、RU/NR、轮胎股 | 保留，但区分上游受益和下游成本压力 |
| 种业 | 隆平高科、登海种业、荃银高科 | 保留，需看作物价格和种子销量 |
| 粮食种植 | 北大荒、苏垦农发 | 保留，需区分粮价上涨和单产受损 |
| 化肥/农药 | 云天化、亚钾国际、新洋丰、扬农化工 | 保留，需看农资价格和订单 |
| 水利抗旱 | 大禹节水 | 保留，需看旱情、政策和招投标 |
| 高温制冷 | 美的集团、格力电器、三花智控 | 旁路观察，不当 ENSO 纯映射 |

明显误读：

- 轮胎股不是天然橡胶涨价的直接受益方。
- 天气概念不等于公司利润改善。
- 厄尔尼诺影响有区域差异，不能把全球气候结论线性映射到中国股票。

## 5. Step 3：产业传导验证

### 5.1 农业链

```text
厄尔尼诺
  ↓
重点产区旱涝异常
  ↓
粮食 / 糖 / 咖啡 / 可可 / 棕榈油产量预期变化
  ↓
商品价格趋势
  ↓
种业 / 农资 / 种植公司利润变化
```

验证数据：

- 作物价格；
- 重点产区天气；
- USDA / FAO 产量预估；
- 公司种子、化肥、农药销量和毛利率。

### 5.2 橡胶链

```text
厄尔尼诺
  ↓
东南亚 / 海南割胶天气异常
  ↓
割胶天数、开割进度、单产受扰
  ↓
RU / NR 天然橡胶价格
  ↓
海南橡胶受益；轮胎厂成本承压
```

验证数据：

- RU / NR 期货价格；
- 东南亚和海南降雨；
- 天然橡胶库存；
- 海南橡胶自产胶利润；
- 轮胎公司毛利率和提价能力。

### 5.3 水利抗旱链

```text
厄尔尼诺
  ↓
区域干旱和水资源压力
  ↓
抗旱、节水灌溉、水利项目需求
  ↓
订单 / 招投标 / 政策资金
  ↓
节水灌溉公司收入确认
```

验证数据：

- 旱情；
- 水利政策；
- 节水灌溉招投标；
- 大禹节水订单和收入。

| 赛轮轮胎、玲珑轮胎、贵州轮胎、风神股份 | 高胶价通常是成本压力，除非提价和出口需求能覆盖。 |
