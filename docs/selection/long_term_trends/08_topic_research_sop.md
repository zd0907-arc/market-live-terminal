# 长期趋势话题研究 SOP

> 目的：以后新增任何长期趋势线索，不再一句一动；必须按固定流水线推进，直到能给出阶段、观察池、验证数据和下一步动作。

## 1. 标准产出

每个长期趋势话题至少落 4 类文件：

1. 研究卡：`docs/selection/long_term_trends/cases/{topic}_{date}.md`
2. 深度计划：`docs/selection/long_term_trends/cases/{topic}_{date}_deep_plan.md`
3. 结构化数据：`data/selection/long_term_trends/{topic}/`
4. 页面日报：`docs/selection/long_term_trends/{topic}/{topic}_tracking_report_{date}.md`

如果话题进入跟踪，还要接入 `/trend-research` 页面。

## 2. 固定流程

### Step 0：线索入库

必须记录：

- 来源：生活观察 / 新闻 / 评论区 / 财报 / 价格数据 / 政策。
- 原始说法：不要改写成结论。
- 初始假设：如果 A 发生，那么 B 价格/订单变化，因此 C 公司利润变化。
- 当前状态：线索 / 观察 / 研究 / 跟踪 / 降级。

### Step 1：真假和概率核验

先核验“事情是否真的发生”：

- 官方定义是什么；
- 当前是否已发生；
- 是确定事实、概率预测，还是市场传言；
- 关键时间点是什么；
- 下一次官方更新是什么时候。

没有过这一关，不允许直接建股票池。

### Step 2：市场讨论扫描

扫描评论区、概念页、股吧、雪球、期货评论、研报摘要，记录市场正在联想什么：

- 关联板块；
- 关联个股；
- 关键词；
- 市场共识程度；
- 明显误读。

注意：这一层只代表“市场怎么炒”，证据等级最高只能到 B/C。

### Step 3：产业传导验证

把市场联想拆成可验证链条：

```text
外部变量
  ↓
需求 / 供给 / 价格
  ↓
企业收入 / 毛利率 / 订单 / 库存 / 现金流
  ↓
估值重估或证伪
```

每条链必须明确：

- 谁是直接受益；
- 谁只是成本承压；
- 谁只是情绪映射；
- 哪个数据出现才算验证。

### Step 4：观察池分层

不是把所有评论区股票都放一起。

统一分层：

| 层级 | 含义 | 动作 |
| --- | --- | --- |
| A | 逻辑最纯、利润可能直接变化 | 核心观察，优先补数据 |
| B | 有间接受益或周期联动 | 观察，等价格/订单确认 |
| C | 情绪映射或反向压力 | 旁路观察，不当核心 |
| X | 逻辑不成立 | 剔除 |

### Step 5：五张表落地

每个话题必须沉淀五张表：

1. `chain_layers.csv`：产业链传导。
2. `industry_signal_log.csv`：需求/供给/价格证据。
3. `a_share_mapping_score.csv`：标的横评和分层。
4. `price_radar.csv`：核心价格和先行指标。
5. `pre_earnings_warning.csv`：后续财报/订单验证点。

有价格和财务数据后，再补：

- `a_share_price_stage_YYYY-MM-DD.csv`
- `a_share_company_snapshot_YYYY-MM-DD.csv`
- `valuation_scenarios_YYYY-MM-DD.csv`

### Step 6：阶段和动作

每次研究必须输出阶段：

| 阶段 | 判定 | 动作 |
| --- | --- | --- |
| 线索期 | 只有现象或评论区联想 | 只记录，不建仓 |
| 概率上升 / 预警期 | 官方概率或先行数据变强 | 建观察池 |
| 价格确认期 | 商品/产品价格趋势上行 | 核心标的深挖 |
| 订单 / 财报验证期 | 公司订单、毛利率、现金流兑现 | 可考虑研究仓 |
| 一致加速期 | 市场全面交易，后排扩散 | 不追主仓，等分歧 |
| 退潮 / 证伪期 | 利好不涨或数据转弱 | 降级 / 退出 |

## 3. 证据等级

| 等级 | 证据 |
| --- | --- |
| S | 官方数据、商品/产品价格趋势、订单/合同、财报兑现 |
| A | 权威行业机构、公司公告、客户 CapEx、招投标 |
| B | 期货评论、研报逻辑、板块资金、概念页 |
| C | 评论区、社媒、单条新闻、生活观察 |

## 4. 禁止事项

- 不允许把“评论区提到”直接等同于“受益”。
- 不允许只建股票池，不写证伪条件。
- 不允许把下游成本压力公司当作上游涨价受益。
- 不允许没有价格、订单或财报验证就升级研究仓。
- 不允许把长期趋势卖点和短线资金卖点混用。
