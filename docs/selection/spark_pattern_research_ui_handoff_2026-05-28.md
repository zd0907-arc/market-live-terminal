## 目标

为选股研究工作台补一套正式的“研究入口 + 形态研究页”体系。

这次不是做摘要表格页，而是做“每只股票一张完整图”的研究页，用来研究某个模型到底选了什么票、图形长什么样、信号前后发生了什么。

## 已确认的业务要求

1. 研究页必须复用现有原型页的样式方向，而不是另起一种全新的展示方式。
2. 每只股票都要有一张完整图。
3. 图上要展示买入前后约 90 个交易日窗口。
4. 图下半部分要保留：
   - 成交量
   - 主力净流入/流出
   - 超大单净流入/流出
5. 图上至少要标记：
   - 信号日
   - 次日买入日
   - 22 日硬退出日
6. 不要靠记 URL 进入研究页，要从选股研究工作台进入。
7. 选股研究工作台顶部要加一个“研究入口”按钮，点开是下拉菜单。
8. 下拉菜单里的每一项都要写完整名称，并说明展示的是哪个模型、看什么内容。
9. 不同模型风格应拆成独立研究页，不要把所有风格堆在一个超长页面里。

## 建议的目标结构

### 研究入口

在选股研究工作台顶部增加一个：

- 按钮名：`研究入口`
- 交互：点击展开下拉菜单

菜单第一批先放这些项：

1. `星火 1.0 形态研究页`
   - 说明：展示星火 1.0 历史选中股票的完整形态、信号与 22 日窗口表现
2. `星火 v2 稳健型形态研究页`
   - 说明：展示“尽量少踩坑、优先后续能稳定冲高”的那套模型
3. `星火 v2 进攻型形态研究页`
   - 说明：展示“优先寻找后续冲得更高的强势票”的那套模型
4. `星火 v2 结果总览页`
   - 说明：展示 2026 检验期的总体统计，不是逐票形态研究

说明：
- 前三项是主要入口。
- 第四项是辅助页，可保留，也可先做成次级入口。

### 页面组织

每个研究页只对应一个模型风格。

页内再提供：

- `Top1`
- `Top3`

两档切换。

不要把稳健型和进攻型做进同一个超长页面。

## 页面实现要求

### 1. 统一模板化

把当前 `SparkPatternPrototypePage.tsx` 抽成可复用模板，不要继续按“一页一份硬拷贝”扩展。

建议拆出：

- 一个通用研究页壳
- 一个股票形态卡组件
- 一个图表配置生成器

但不要过度抽象，保持最小够用。

### 2. 图表要求

在现有原型页基础上补齐：

- 信号日标线
- 次日买入日标线
- 22 日硬退出日标线

现有原型页只标信号日和硬退出日，这次要把买入日补上。

### 3. 信息层级

每张股票卡至少展示：

- 股票名 / 代码
- 该股票被命中的次数
- 首次信号日 / 末次信号日
- 最佳 22 日冲高
- 平均 22 日冲高
- 平均 22 日收盘收益
- 最差最大回撤

### 4. 页面标题命名

页面标题必须是业务名称，不要只放内部实验编号。

例如：

- `星火 1.0 形态研究页`
- `星火 v2 稳健型形态研究页`
- `星火 v2 进攻型形态研究页`

内部模型编号只作为辅助信息，不要做主标题。
