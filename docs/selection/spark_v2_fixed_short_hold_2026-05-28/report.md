# 星火 v2 固定超短持有验证

## 口径

- D 日盘后得到信号
- D+1 开盘买入
- 固定持有 1 / 2 / 3 个交易日后，在目标日开盘卖出
- 若卖出日开盘跌停无法卖出，则顺延到下一个可卖出开盘
- 买卖都计入与星火 1.0 研究脚本一致的滑点与费用
- 账户层用固定槽位模拟：1 日持有用 1 槽，2 日持有用 2 槽，3 日持有用 3 槽
