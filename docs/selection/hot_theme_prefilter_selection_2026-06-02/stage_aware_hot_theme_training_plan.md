# 热点提前识别 + 分阶段选股联动训练计划

## 先给结论

下一步不建议直接训练一个“热点新模型”，更适合拆成两层：

1. 先训练一个“热点阶段提前识别层”，回答哪些板块正在从普通状态走向 `首次新热 / 持续升温 / 主线再加速 / 持续主线`。
2. 再训练或验证一个“阶段感知选股层”，回答不同热点阶段下，应该调用哪类个股模型、哪些票该追、哪些票该避开。

这条路线的核心不是“让模型更会追当天最热”，而是把买点往前挪，在板块真正上榜前 1 到 3 天就先识别出来。

## 为什么要这样做

这次已经验证过一个事实：

- 热点直接加分不稳，历史上已经偏负。
- 热点做前置过滤有时有效，但不是常开就赢。
- 2026-01 到 2026-04 更适合 `快反馈模型 + 某些热点池过滤`。
- 2026-05 这种普涨快反馈月里，原最优过滤组合又明显掉速。

所以问题不在于“热点没用”，而在于：

- 我们现在识别到热点的时候，往往已经太晚。
- 板块已经走了 5 到 10 天，今天再大涨才正式变热。
- 这时再用热点去追，容易买到板块后段、高潮段、次日难受段。

真正该做的是提前识别“热度形成过程”，而不是只吃“热点结果快照”。

## 这条线要回答的两个核心问题

### 问题 1：哪些板块正在变热，而不是已经很热

不是预测“今天谁在榜上”，而是预测：

- `D 日收盘时，哪些板块会在 D+1 ~ D+3 进入 首次新热`
- `哪些板块会从观察/普通状态走到 持续升温`
- `哪些板块会从普通主线走到 主线再加速`
- `哪些板块已经太晚，应该视为后段风险`

### 问题 2：不同板块阶段，个股该用不同打法吗

我建议默认按下面这个框架去验证：

- `首次新热 / 持续升温`
  优先看快反馈模型，目标是抢前排、抢次日冲高。

- `持续主线`
  优先看低痛稳健模型，目标是做核心股承接、回踩、趋势延续。

- `主线再加速`
  不默认追龙头。优先验证两种路线：
  1. 直接降权或禁追；
  2. 只看低位补涨、换手更健康的票。

- `退潮观察`
  默认排除，不作为日常正向候选池。

## 整体落地顺序

这件事不要一口气训练一个大而全的系统，建议按 4 步落地。

## 第 1 步：先把“热点提前识别”标签定义清楚

这一层不是个股标签，而是板块标签。

### 1.1 目标标签

建议先做 3 组标签：

- `future_first_hot_3d`
  D 日后 3 个交易日内，板块是否会进入 `首次新热`

- `future_warming_or_first_hot_3d`
  D 日后 3 个交易日内，板块是否会进入 `持续升温` 或 `首次新热`

- `future_accel_3d`
  D 日后 3 个交易日内，板块是否会进入 `主线再加速`

这 3 组标签分别对应：

- 提前发现新热点
- 提前发现从普通到升温的过程
- 提前识别加速和潜在高潮风险

### 1.2 训练口径

标签来源必须继续沿用你现在正式 6 池的业务定义，不要重新发明一套“看起来差不多”的池子名字。

建议做法：

- 用正式热点长表或正式热点服务重建出的每日板块快照
- 用同一套生命周期规则回放历史
- 在 D 日只使用当日及之前可见信息，生成 D 日训练特征
- 用 D+1 ~ D+3 是否进入目标池，生成监督标签

### 1.3 先不做的事

- 不先做个股收益标签
- 不先训练个股排序模型
- 不先讨论“模型融合怎么加权”

先把“能不能提前 1 到 3 天识别出正在起势的板块”验证清楚。

## 第 2 步：做板块级“提前识别模型”

### 2.1 样本单位

样本单位建议用：

- `trade_date + theme_id`

也就是每个交易日的每个细分板块一条样本。

### 2.2 特征方向

重点不是当天涨了多少，而是“趋势形成过程”。

建议优先做这几组特征：

- 热度排名变化
  `hot_rank_1d_change`
  `hot_rank_3d_change`
  `hot_rank_5d_change`
  `hot_score_3d_slope`
  `persistence_score_3d_slope`

- 扩散度变化
  `member_up_ratio`
  `member_big_up_count`
  `member_limit_up_count`
  `member_positive_ratio_3d_trend`
  `top3_concentration_change`

- 资金持续性
  `l2_net_inflow_1d / 3d / 5d`
  `amount_ratio_3d / 5d`
  `连续净流入天数`

- 趋势位置
  `return_3d / 5d / 10d / 20d`
  `板块距离 20 日高点`
  `板块 5 日位置 / 10 日位置`
  `是否已过热`

- 龙头与补涨结构
  `龙头强度 - 第二梯队强度`
  `第二梯队数量`
  `首板 / 二板 / 大阳线家数`
  `是否只有单一龙头硬顶`

- 市场环境
  `市场情绪强弱`
  `指数位置`
  `连板生态`
  `热点轮动速度`

### 2.3 第一轮模型目标

第一轮不要追求复杂。

建议直接做 3 个简单二分类模型：

1. `未来 3 日进入 首次新热`
2. `未来 3 日进入 持续升温或首次新热`
3. `未来 3 日进入 主线再加速`

模型可以先用：

- LightGBM
- Logistic Regression baseline

先看：

- Precision@TopN 板块
- Recall
- 月度稳定性
- 提前量
  也就是在真正上榜前，平均能提前几天给出有效提示

## 第 3 步：做“阶段感知选股联动”验证

只有当第 2 步证明板块级提前识别是有效的，才进入这一步。

### 3.1 联动方式

不是让一个模型同时学所有事情，而是用路由思想：

- 先判断板块处于什么阶段
- 再决定给这个板块里的股票调用哪类选股器

### 3.2 第一轮建议先测 4 种联动规则

#### 规则 A：新热点抢先手

- 如果板块被预测为 `未来 3 日进入 首次新热 / 持续升温`
- 候选池限定到这些板块
- 个股排序用 `闪击 1 天`

业务目标：

- 提前抓到次日冲高更快的票

#### 规则 B：主线趋势承接

- 如果板块当前已接近 `持续主线`
- 但还没进入明显高潮
- 个股排序优先用 `低痛稳健模型`

业务目标：

- 不追最热，做趋势中段里更舒服的承接票

#### 规则 C：主线加速风险控制

- 如果板块被预测为 `未来 3 日进入 主线再加速`
- 不直接正向加分
- 先验证两种策略：
  1. 直接降权
  2. 只保留低位补涨票，再用快反馈模型选

业务目标：

- 避免冲在高潮段山顶

#### 规则 D：双层结构

- 第 1 层：板块提前识别模型给出阶段概率
- 第 2 层：个股模型在板块内排序
- 第 3 层：再加一个简单规则层处理高潮/退潮风险

业务目标：

- 同时兼顾“早点发现”和“别买得太难受”

## 第 4 步：最后才考虑训练“阶段专用个股模型”

只有当前 3 步已经证明：

- 板块提前识别有效
- 阶段切模型比统一模型更好

这时才值得训练阶段专用模型。

### 4.1 可以训练的专用模型

- `新热点快反馈模型`
  只在未来 3 日可能进入 `首次新热 / 持续升温` 的板块里训练

- `主线承接模型`
  只在 `持续主线` 中段样本里训练

- `加速风险回避模型`
  专门学哪些加速板块里的票容易次日难受

### 4.2 不建议一开始就做

因为如果板块路由本身没价值，后面这些专用模型大概率只是过拟合。

## 训练与验证切分

建议继续沿用现在已经固定的切分原则：

- 训练区：`2024-09-02 ~ 2025-09-30`
- 内部验证 A：`2025-10-08 ~ 2025-11-28`
- 内部验证 B：`2025-12-01 ~ 2025-12-31`
- 最终检验：`2026-01-05 ~ 2026-04-13`

额外补充：

- `2026-05` 继续只作为补充外样本，不得回流训练
- 如果未来要加 `2026-05`、`2026-06` 做滚动验证，也只能做事后复核，不参与选模

## 评估指标要分两层

## A. 板块提前识别层

至少看：

- TopN 板块命中率
- 提前 1 日命中率
- 提前 3 日命中率
- 假阳性率
- 月度稳定性
- 各阶段样本覆盖度

最重要的不是 AUC，而是：

- 能不能在正式上榜前把板块抓出来
- 抓出来以后，后续是否真的有持续性

## B. 个股联动层

继续沿用现在的业务指标：

- 买入当天从未翻红比例
- 次日收盘仍亏比例
- 明显难受比例
- 买入当天平均最高冲高
- 次日平均收益
- 当天冲到 3% / 5% 的比例
- 月度稳定性

但要多加两组对照：

- `全市场直接选股` vs `阶段联动选股`
- `热点结果过滤` vs `热点提前识别过滤`

这一步要回答的不是“收益更高了吗”，而是：

- 是不是更早了
- 是不是更少追在热点后段
- 是不是更符合少痛 + 快反馈

## 第一轮最小可执行版本

如果只做一个最小闭环，我建议是这个：

### 阶段 1：先做板块提前识别

- 目标：预测 `未来 3 日进入 首次新热 / 持续升温`
- 输出：每天一个“候选板块提前名单”

### 阶段 2：只接一个个股模型

- 在这些提前名单板块里
- 只跑 `闪击 1 天模型`

### 阶段 3：看是否比“正式热点出来后再选股”更早、更舒服

只回答一个问题：

- `提前识别 + 闪击 1 天` 是否比 `热点正式上榜后 + 闪击 1 天` 更符合业务目标

如果这一步都不成立，就没必要往更复杂的阶段切模型继续加。

## 第二轮再做阶段切模型

只有第一轮成立，第二轮再上：

- `提前识别新热点 -> 闪击 1 天`
- `持续主线中段 -> 低痛稳健`
- `主线再加速 -> 风险控制 / 低位补涨`
