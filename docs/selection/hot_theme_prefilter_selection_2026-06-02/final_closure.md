# 热门板块过滤 + 模型联动研究收口

## 最终结论

这轮研究可以正式收口。

结论不是“热门板块没用”，而是：

- `热门板块上榜后，再和现有选股模型做前置过滤联动`，不适合直接作为正式主策略。
- `热点正式上榜后的过滤`，在部分窗口能改善结果，但不稳定，不能默认常开。
- `提前识别热点趋势形成过程` 这个方向有研究价值，但当前正式执行版还没有打赢现有正式路由，不具备上线条件。

所以这轮应该收口成两个明确判断：

1. `热门板块上榜后再过滤` 这条主想法，不值得继续当正式方向深挖。
2. 如果未来还要继续碰热点，应该转向 `提前识别趋势形成过程`，而不是继续围绕“热点上榜后怎么过滤”打转。

## 这轮到底验证了什么

### 第一层：热点正式上榜后再过滤

这部分已经验证过：

- 历史上 `热点直接加分` 偏负，不该回头再走。
- 换成 `热点做候选池过滤`，在 `2026-01 ~ 2026-04` 里最好的组合是：
  `闪击 1 天 + 首次新热 / 主线再加速 / 持续主线`
- 但到 `2026-05` 的补充外样本里，这个组合又明显失效。

业务含义很明确：

- 热点上榜后过滤，不是稳定 alpha。
- 它更像阶段性市场适配，而不是长期可靠规则。

### 第二层：提前识别趋势形成过程

这部分继续往前做了三版：

- `MVP`
  只验证“未来 3 日会升温/新热”后接 `闪击 1 天`

- `v1 / v2`
  把板块扩散、成员强弱、龙头集中度拉进来，改成“趋势形成过程训练”

- `v3 formal`
  按正式流程执行：
  用 `2025` 内部验证选参数；
  用 `2026` 独立做最终检验；
  不让 `2026` 参与选参。

这条线的研究结论也很清楚：

- 方向有信号；
- 但正式执行版在 `2026` 上没有超过现有正式热点路由；
- 所以它还不具备上线条件。

## 为什么决定收口

不是因为没有任何正向结果，而是因为已经拿到了足够清楚的业务答案。

### 已经清楚的事

- `热点上榜后再过滤` 不是一条稳定正式路。
- 它会受市场阶段影响很大。
- 在某些窗口有效，在另一些窗口会明显失效。
- 一旦做成正式固定规则，回撤和失真风险都太大。

### 不值得继续投入的事

- 继续围绕“热点上榜后哪几个池子更适合过滤”反复打补丁。
- 继续对现有热点过滤规则做小阈值微调。
- 继续在 `热点正式上榜后` 这个时间点上追求更优过滤器。

这些事情边际价值已经很低。

## 这轮最值得留下来的研究资产

即使收口，这轮也不是白做。

至少留下了 4 个有价值的结论：

1. `退潮观察` 不适合作为正向候选池。
2. `低痛稳健模型 + 热点上榜后过滤` 不适合，容易失真。
3. `快反馈模型` 和热点有联动空间，但更适合更早阶段，不适合等上榜后再追。
4. 如果以后继续做热点，正确问题应该是：
   `怎么提前识别趋势形成，而不是怎么处理已经上榜的热点。`

## 对主分支应该沉淀什么

合并回主分支时，建议沉淀的是：

- 正式研究目录和结果文档
- 关键研究脚本
- 收口文档

不建议把这轮包装成“新正式模型”。

主分支里应该保留的，是清楚证据和清楚边界：

- 试了什么
- 哪些阶段有效
- 哪些阶段失效
- 为什么不建议上线

## 最后的业务判断

这轮研究的主结论可以浓缩成一句话：

`热门板块正式上榜后，再结合现有模型做过滤，不适合做正式主策略；如果以后还要继续研究热点，应该转向提前识别趋势形成过程。`

而这次进一步推进到正式执行后，最终判断是：

`趋势形成过程训练值得保留为后续研究方向，但当前版本还不具备合并成正式交易路由的条件。`
