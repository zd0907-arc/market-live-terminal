# 翻倍股案例库使用体系

## 1. 案例库目标

这个库不是用来证明某只股票一定会涨，而是用来回答四个问题：

1. 现在这只票更像哪一类历史翻倍股？
2. 它的驱动是商品价格、业绩、重组、题材问答，还是资金情绪？
3. 当前处在低位埋伏、突破确认、一波高潮、二波修复，还是高位兑现？
4. 什么信息出现时应该继续拿，什么信息出现时应该退出？

## 2. 每个案例必须保留的字段

| 字段 | 用途 |
| --- | --- |
| `细分方向` | 判断它属于哪条产业链或商品链，避免只看大行业。 |
| `案例类型` | 把样本归到可复用模式，例如商品涨价、控制权变更、重组、业绩反转、题材问答。 |
| `点火链条` | 记录低点、启动、公告/新闻、峰值之间的先后顺序。 |
| `消息先后` | 判断是消息前资金埋伏，还是消息明牌后接力。 |
| `可复用条件` | 以后筛新票时必须满足的条件。 |
| `风险/出场` | 记录该类票最常见的结束方式。 |
| `外部核验` | 留下公告、问答、新闻链接，避免后续只凭印象复盘。 |
| `案例库标签` | 给后续检索和相似度匹配使用。 |

## 3. 当前Top20的主要模式

| 模式 | 样本 | 核心逻辑 | 适合怎么用 |
| --- | --- | --- | --- |
| 商品涨价型 | 翔鹭钨业、湖南白银、章源钨业、晓程科技、白银有色、四川黄金 | 商品价格先行，公司业绩或资源纯度后确认。 | 先跟踪期货/现货价格，再找板块内最先突破的小市值或高纯度标的。 |
| 控制权/重组型 | 锋龙股份、凯龙高科、嘉美包装 | 公司业务被新主或收购资产重新定义。 | 重点看新资产能不能改变市场认知，而不是看原主业。 |
| 题材问答型 | 志特新材、顶固集创、欧莱新材、欧科亿、田中精机 | 互动问答把公司贴到热门主题。 | 必须区分“已有订单/验证”与“研发/参股/未量产”的强弱。 |
| 业绩确认型 | 利通电子、欧科亿、德才股份 | 价格先强或同步强，业绩预增/扭亏给继续上涨理由。 | 适合突破后确认，不适合死等最低点。 |
| 主线扩散型 | 赛恩斯、江钨装备、通源石油、奥特维 | 主线从核心票扩散到服务商、设备商、平台票。 | 用来寻找二线补涨，但要更重视高位兑现风险。 |

## 4. 新票匹配流程

1. 先定细分方向：不要只写“有色”“机器人”，要写到“钨矿”“商业航天刀具”“机器人精密传动”这种粒度。
2. 拉时间线：低点、首次突破、第一条强消息、第一次异动公告、峰值、回撤低点。
3. 判断消息先后：如果价格先突破，按“资金先行型”；如果停牌/公告后连板，按“明牌事件型”。
4. 匹配案例标签：用`商品涨价`、`控制权变更`、`业绩预增`、`订单问答`、`官方降温`、`二波修复`等标签找相似样本。
5. 对照风险：新票如果已经出现历史样本里的出场触发，就不能只看上涨空间。

## 5. 操盘判断模板

| 当前状态 | 应该找的证据 | 对照案例 |
| --- | --- | --- |
| 低位刚异动 | 是否有资金先行、板块共振、低位新高。 | 利通电子、章源钨业、德才股份 |
| 公告后连板 | 公告是否改变公司业务定义，新资产是否足够热门。 | 锋龙股份、凯龙高科、嘉美包装 |
| 一波后回撤 | 回撤期间消息是否被证伪，资金是否还能回补。 | 志特新材、江钨装备、通源石油 |
| 二波突破 | 是否有新的消息续命，而不是只靠老题材反抽。 | 利通电子、欧科亿、通源石油 |
| 高位滞涨 | 是否出现监管、减持、澄清、商品价格回落、订单不及预期。 | 湖南白银、四川黄金、锋龙股份 |

## 6. 出场触发清单

| 触发 | 含义 |
| --- | --- |
| 商品价格掉头 | 商品涨价型先减仓，不等公司公告确认。 |
| 官方明确降温 | 研发阶段、未量产、无收入、不涉及热门业务，题材票降级。 |
| 控制权/重组推进放缓 | 明牌事件票进入兑现区。 |
| 业绩公告落地后不再新高 | 业绩确认从催化变成兑现。 |
| L2连续转负且高位滞涨 | 资金从主升切到派发。 |
| 异动公告后承接失败 | 情绪强票不能再用主升逻辑持有。 |

## 7. 后续扩库规则

每新增一批翻倍股，都按同一结构补齐：

1. 先生成价格和阶段表。
2. 再补本地事件库里的公告、问答、新闻。
3. 对关键催化做外部链接核验。
4. 最后写`案例库补齐`段，把样本归类到可复用模式。
