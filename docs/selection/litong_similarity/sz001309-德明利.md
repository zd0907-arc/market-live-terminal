# 德明利 `sz001309` 利通相似度专项

## 结论

德明利是当前最强的“利通相似度”样本，但它不是低位版利通。它的相似点是单季利润模型被重估，差异点是利润来源更偏存储周期和库存价差，而不是利通那种算力业务模式切换。

截至 2026-04-30，收盘 524.81 元，按 2.26845658 亿股粗算市值约 1191 亿。2024-09 低点约 49.39 元，到 2026-04 高点 544.93 元，已经约 11 倍。

## 公司业务

德明利主业是闪存主控芯片设计、存储模组产品方案开发和存储模组销售。产品线包括固态硬盘、嵌入式存储、内存条、移动存储，并向数据中心、消费电子、工业控制、通信电力、安防监控等场景提供存储解决方案。

关键点：它不是三星、海力士、美光这种原厂，也不是纯 HBM 公司。它更像“存储模组/企业级存储解决方案商”，核心受益来自 NAND/DRAM 涨价、库存管理、产品结构和客户项目放量。

## 行业环境

这轮存储涨价和 AI 服务器需求直接相关。TrendForce 在 2026-02-02 上修 1Q26 存储价格预期，称 AI 和数据中心需求加剧供需失衡；在 2026-03-31 又预计 2Q26 conventional DRAM 合约价季增 58%-63%，NAND Flash 合约价季增 70%-75%。

所以德明利 Q1 不是孤立事件，Q2 行业价格仍在顺风里。问题不是“有没有逻辑”，而是市场会不会按 Q1 年化给估值。

## 盈利持续性专项

结论：德明利 Q2 继续高盈利的概率不低，但 Q1 的 57.42% 毛利率不应线性外推。它的持续性分两层：行业价格顺风大概率还在，单公司超高毛利能否持续取决于低成本库存、订单价格和产品结构。

需要搞清楚的问题：

| 问题 | 已知证据 | 结论 |
| --- | --- | --- |
| 存储价格是否继续涨 | TrendForce 预计 2Q26 conventional DRAM 合约价环比 +58%-63%，NAND Flash 合约价环比 +70%-75% | Q2 行业顺风仍强 |
| 企业级 SSD 是否继续紧缺 | TrendForce 称企业级 SSD 订单没有放缓迹象，2026 年预计明确短缺，明显扩产要到 2027 年末或 2028 年 | 德明利的数据中心/企业级方向有持续需求支撑 |
| 公司是否只是一次性利润 | 2026Q1 扣非净利 33.34 亿，非经常损益只有 0.12 亿左右 | 不是会计一次性收益 |
| 利润是否来自低成本库存 | 公司业绩预告明确提到前期充足原材料战略储备，Q1 存储价格持续上涨 | Q1 高毛利有库存价差成分 |
| 低成本库存还能支撑多久 | 2026Q1 存货 121.92 亿，较 2025 年末继续 +72.73%；购买商品现金 82.69 亿，接近销售收现 85.59 亿 | 公司仍在高位备货，新库存成本会抬升 |
| 订单/需求是否真实 | 合同负债 13.34 亿，较 2025 年末 +113.90%；Q1 报告称企业级存储重点客户合作深化、落地项目数量提升 | 需求不是纯预期，但未披露客户与订单明细 |
| 现金流是否支持扩张 | Q1 经营现金流 -2.41 亿，2025 全年 -22.41 亿；短债 37.42 亿、长债 20.45 亿 | 增长依赖融资和库存周转，财务弹性不如利润表好看 |

我的判断：

1. Q2 大概率还能保持强盈利，因为行业价格在 3 月底仍被上修，且企业级 SSD 供给紧张延续。
2. Q1 这种 33 亿单季净利能否复制，核心看毛利率。如果毛利率从 57% 回落到 35%-40%，即使营收继续高，单季利润也会明显低于 Q1。
3. 最危险的不是 Q2，而是后面某个季度出现“价格涨幅放缓 + 高价库存累积 + 客户砍单”。那时利润会从超级弹性变成存货跌价风险。
4. 所以估值不能简单用 Q1 年化 134 亿利润。更合理是分情景看：2026 年 70 亿利润是偏保守可跟踪，90 亿以上需要 Q2 继续爆，100 亿以上才支撑再翻倍叙事。

后续必须跟踪：

- 6 月前后是否有 Q2 业绩预告。
- Q2 毛利率是否仍在 45% 以上。
- 存货是否继续上升，如果营收没同步扩张但存货继续大增，要警惕。
- 合同负债是否维持 13 亿以上或继续增加。
- TrendForce/CFM 对 3Q26 DRAM、NAND、企业级 SSD 的价格展望是否继续上修。
- 公司是否披露企业级 SSD 客户、批量项目、订单持续性，而不是只讲行业景气。

## 成本敏感性估值模型

模型口径：

- 以 2026Q1 报表为基准。
- Q1 营收 75.38 亿，营业成本 32.10 亿，毛利率 57.42%。

## 和利通电子对照

| 维度 | 利通电子 | 德明利 |
| --- | --- | --- |
| 利润突变 | 算力经销/租赁业务放大利润 | 存储涨价 + 库存价差 + 企业级项目 |
| 业务变化 | 原有消费电子估值锚失效，切到算力 | 主业仍是存储，只是应用和周期变强 |
| 可持续性 | 看经销/租赁订单能否复制 | 看存储价格、低成本库存和项目订单 |
| 风险 | 算力供应、芯片、经销持续性 | 存货跌价、价格反转、现金流和融资 |
| 当前位置 | 财报确认前仍有二波空间 | 已从 2024-09 低点约 11 倍 |

德明利更像“利通的利润重估 + 钨/白银涨价链的周期弹性”，不是纯粹的利通复制。

## 操作判断

我不会在 525 附近无条件重仓追。它有继续上涨逻辑，但当前风险收益不对称。

更合理的处理：

| 情况 | 动作 |
| --- | --- |
| 放量突破 545，且当日 L2 主力净流入明显为正、OIB 重新转强 | 可以按趋势确认小仓参与 |
| 回踩 489-500 不破，L2 不连续净流出 | 可以试仓，性价比好于直接追 |
| 回踩 20 日线附近 470-480，并且行业存储价格继续上修 | 更好的风险收益点 |
| 跌破 447 且 L2 连续转负 | 视为主升结构破坏 |
| Q2 预告/中报没有继续高利润，或存储价格出现反转 | 估值锚失效，必须降级 |

最重要的跟踪指标：

- TrendForce/CFM 的 DRAM、NAND、企业级 SSD 价格是否继续上修。
- 公司 Q2 是否继续出现高毛利，而不是 Q1 一次性库存价差。
- 存货是否继续高周转，不能只堆库存。
- 合同负债/预收款是否继续上升。
- 4/23 这种高位大分歧后，后续 L2 是否能持续修复。
