# 利通相似度池

目标：从全市场财报披露中，筛出“利润模型突变 + 当时热点共振 + 价格资金确认”的候选股，用来寻找利通电子式估值重构机会。

当前版本：

- [2026Q1 利通相似度池](20260331_20260430.md)

生成脚本：

```bash
python backend/scripts/build_litong_similarity_pool.py --report-date 2026-03-31 --trade-date 2026-04-30
```

注意：

- 这不是正式买入策略，只是研究池。
- 当前本地 L2 覆盖以主板为主，创业板/科创板强财务票需要单独补资金、消息和估值。
