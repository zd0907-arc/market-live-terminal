# 2026Q1 存储链三票：江波龙 / 佰维存储 / 香农芯创

## 结论

三只里，我的优先级是：

1. 江波龙 `sz301308`：财务强度最高，业务质量最好，最值得继续跟踪。
2. 佰维存储 `sh688525`：弹性强，但 4 月 L2 派发最重，必须等资金修复。
3. 香农芯创 `sz300475`：位置和弹性不错，但本质更偏分销，估值倍数应低于江波龙/佰维。

这三只不是本地没有 L2。它们在 `market_data.db` 的 `history_daily_l2/history_5m_l2` 里有 2026-03-02 至 2026-04-30 数据；缺口在于新的 `atomic_facts/selection_feature` 派生库没有把创业板/科创板 20cm 标的同步进去。

## 行业背景

TrendForce 2026-03-31 判断，2Q26 conventional DRAM 合约价预计环比上涨 58%-63%，NAND Flash 合约价预计环比上涨 70%-75%。AI 和数据中心需求继续推高企业级 SSD，2026 年预计明确短缺，明显扩产要到 2027 年末或 2028 年。

所以三只票的共同前提是：Q2 存储价格仍在上行，企业级 SSD/服务器 DRAM 需求仍强。真正分歧不在行业，而在每家公司能否把行业涨价转化成持续利润。

## 香农芯创 `sz300475`

### 业务与利润

香农芯创本质是电子元器件分销商，核心代理 SK 海力士、MTK，并有 AMD 经销资质。分销业务是基本盘；自有品牌“海普存储”是重估点，2025 年收入 16.58 亿，同比增长超过四倍，企业级 DDR4/DDR5、Gen4 eSSD 已进入量产阶段。

2026Q1：

| 指标 | 数值 |
| --- | ---: |
| 营收 | 237.65 亿 |
| 归母净利 | 13.27 亿 |
| 净利同比 | 7835% |
| 毛利率 | 9.12% |
| EPS | 2.86 元 |

2025 全年营收 352.51 亿，净利 5.45 亿；Q1 净利已经是 2025 全年的 2.44 倍。

### 估值

4/30 收盘 174.70 元，按 EPS 反推股本约 4.64 亿股，市值约 811 亿。

| 年利润假设 | 当前PE | 20x PE 对应股价 |
| ---: | ---: | ---: |
| 26.5 亿 | 30.5x | 114 |
| 39.8 亿 | 20.4x | 172 |
| 53.1 亿 | 15.3x | 229 |

判断：按 Q1 年化看不贵，但因为毛利率只有 9.12%，本质仍是分销低毛利模式，估值倍数应低于江波龙/佰维。真正的重估点在海普存储能不能从 16.58 亿收入继续放量并提升利润率。

3-4 月区间低点 134.37，高点 178.78，4/30 收 174.70。成交 1389 亿，L2 主力合计 -23.31 亿，超级单 -13.02 亿。

- 4/24：L2 +1.40 亿。
- 4/27：L2 +3.54 亿。
- 4/28：L2 +0.11 亿。

结论：香农位置比江波龙/佰维温和，业务重估也更清楚，但利润质量不如两家高毛利存储模组公司。更适合作为“海普存储产品化”观察票，不适合给太高估值。
