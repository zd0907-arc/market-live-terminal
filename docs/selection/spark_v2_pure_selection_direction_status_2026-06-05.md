# 星火 v2 纯选股方向状态

更新时间：2026-06-05

## 结论

这个方向有持续研究价值，但当前还没有形成可替代星火 1.0 原始机会分的新正式主模型。

当前判断：

- 继续推进
- 但只允许 `watch_only / research_only`
- 还不允许直接接入正式自动候选主线

## 它在解决什么问题

- 盘后纯选股
- 希望选出来的票，未来 22 个交易日更大概率出现可吃的冲高
- 同时减少那种买后一路阴跌、几乎不给机会的票

## 它和现有方向的区别

- 和星火 1.0 的区别：这条线用更长历史、更统一特征库和更严格时间切分做重训
- 和次日 / 超短的区别：它不是追次日反馈，而是看未来 22 日机会
- 和热点 / 市场过滤的区别：它本身是主选股线，不是附属过滤器
- 和持仓模型的区别：它只回答“买什么”，不回答“买后怎么卖”

## 当前结论

- v2 当前已经能稳定强于星火 1.0 系统展示排序
- 但还没有稳定打赢星火 1.0 原始机会分
- 稳定冲高方向和高命中专项已经产出可保留候选
- 2026 没有参与训练、调参或选模，这些结果可作为正式研究证据

## 当前未解决问题

- 怎么把“平均冲高”和“少踩空”更稳定地统一起来
- 市场状态分层是否应该进入正式选模
- 哪些新增特征是真正有泛化价值，哪些只是阶段噪声
