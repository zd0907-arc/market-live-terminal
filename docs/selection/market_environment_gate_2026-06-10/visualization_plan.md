# 市场环境水位可视化方案

## 结论

工作台第一屏要表达“今天能不能新开仓”，不是做收益榜。防守状态下，主视觉必须明确显示“暂停新开仓；候选仅观察”。

## 首页主视觉

### 1. 市场水位卡

字段来源：`market_state_daily.csv`

展示：

- 日期。
- 水位：攻击、谨慎、防守。
- 细分状态：防守-持续下跌、防守-弱势承压、防守-修复观察。
- 默认动作：可参与、观察为主、暂停新开仓。
- 三条业务原因。

防守文案：

```text
暂停新开仓；候选仅观察，不作为买入建议；等待环境修复或例外被数据证明。
```

谨慎文案：

```text
观察为主；只跟踪环境允许的来源，未确认修复前不主动扩大参与。
```

攻击文案：

```text
环境允许参与；仍按来源规则和个股风险筛选，水位不等于自动买入。
```

## 趋势图

### 2. 综合水位折线

字段来源：

- `trade_date`
- `water_score`
- `market_regime`
- `market_detail_label`

表达方式：

- 折线展示水位分数。
- 背景分成攻击、谨慎、防守三段。
- 鼠标悬停显示当天三条原因。

业务目的：

- 一眼看到市场水位是在抬升还是继续下降。
- 识别当前是下跌途中，还是弱市修复。

### 3. 多周期上涨占比柱状图

字段来源：

- `all_up_ratio_1d`
- `all_up_ratio_3d`
- `all_up_ratio_5d`
- `all_up_ratio_10d`
- `all_up_ratio_20d`

业务目的：

- 区分单日反弹和多周期修复。
- 防止一天反弹就误判为环境转好。

### 4. 中位涨跌幅对比图

字段来源：

- `all_med_ret_5d`
- `small_med_ret_5d`
- `large_med_ret_5d`
- `all_med_ret_20d`
- `small_med_ret_20d`
- `large_med_ret_20d`

业务目的：

- 识别“指数没那么差，但小票很难做”。
- 给试盘识别和趋势延续策略提供环境解释。

## 门控效果图

### 5. 门控策略对比表

字段来源：

- `gate_policy_comparison_5d.csv`
- `gate_policy_comparison_10d.csv`
- `gate_policy_comparison.csv`

首页只展示风险列：

- 覆盖率。
- 5 日或 10 日收盘亏 5% 比例。
- 回撤 8% 比例。
- 踩坑率。

机会列放二级展开：

- MFE。
- 冲高命中率。
- 被拦截后错过的大机会。

### 6. 来源 x 市场状态矩阵

字段来源：

- `gate_summary_by_source_regime.csv`
- `gate_summary_by_source_detail.csv`

展示顺序：

1. 星火机会模型。
2. 资金流回调稳健策略。
3. 趋势延续策略。
4. 试盘识别。

每个来源按攻击、谨慎、防守展示：

- 样本数。
- 踩坑率。
- 回撤 8% 比例。
- 收盘亏 5% 比例。
- 冲高命中率。

业务目的：

- 回答“什么市场环境下该信哪个来源”。
- 不把四个来源做成简单收益排名。

## 候选列表表达

候选仍展示，但防守环境下不能暗示买入。

标签：

- `环境允许`
- `仅观察`
- `暂停新开仓`
- `高置信例外未通过`

防守候选示例：

```text
仅观察：当前为防守-持续下跌，5 日上涨占比 19.0%，小盘 5 日上涨占比 11.9%。该来源未被证明能穿越当前环境。
```

## 复盘区

字段来源：

- `candidate_outcomes.csv`
- `gate_policy_comparison_5d.csv`
- `gate_policy_comparison_10d.csv`

必须展示：

- 被市场门控拦截的候选。
- 拦截原因。
- 后续 5 日、10 日是否踩坑。
- 是否错过大冲高。
- 错过是否可接受。

复盘口径：

- 用于校准门控，不用于追责用户人工决策。
- 当前阶段不记录真实买卖操作，不做真实账户收益归因。

## 不放首页主视觉的内容

以下内容容易误导，不放在主视觉：

- 平均收益榜。
- 单票高分榜。
- Top1/Top3 推荐榜。
- 最大冲高榜。
- 未通过验证的高置信例外。
- 被拦截后走牛的单票案例。

这些内容可以放在复盘二级页面，用于解释误杀成本。
