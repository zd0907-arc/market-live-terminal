# S06 下一轮短周期机会模型计划

## 目标

当前 22 日模型证明了一件事：

```text
盘后选出的 Top1，在未来 22 个交易日内出现 15% 以上冲高的概率较高。
```

下一轮要验证的问题是：

```text
如果把持仓周期缩短到 2/3/5/7/10 个交易日，
能不能更稳定地抓到 5%/8%/10% 的短线冲高，
并且让一个月账户收益更高、资金周转更快、回撤更小。
```

这仍然是选股模型研究，不是完整操盘系统。

## 基本交易设定

所有短周期模型都保持同一套入场口径：

```text
D 日盘后出信号。
D+1 开盘作为理论买入价。
如果 D+1 开盘高开超过阈值则不买。
如果 D+1 接近涨停/一字板则不买。
如果 D+1 极端低开则不买。
买入按 100 股一手取整。
买入滑点 15bp，卖出滑点 15bp，双边费用 20bp。
A股 T+1，买入当天不能卖。
同股持仓中不重复加仓。
```

高开阈值不是固定死一个值，需要网格搜索：

| 入场阈值 | 含义 |
|---|---|
| `gap <= 3.0%` | 保守，不追高 |
| `gap <= 5.0%` | 中性 |
| `gap <= 6.8%` | 延续当前 22 日模型口径 |
| `gap <= 8.0%` | 更激进，接力属性更强 |

用户提到“挂高开 6.8% 买”的逻辑，在回测里等价于：

```text
只要开盘涨幅 <= 6.8%，认为可以按开盘价买到。
开盘涨幅 > 6.8%，认为不买。
接近涨停/一字板，不买。
```

## 候选模型组

下一轮建议训练 4 组短周期模型：

| 模型 | 预测窗口 | 核心目标 | 适用风格 |
|---|---:|---|---|
| `S06-H2` | 2 个交易日 | 2日内冲高 5% | 超短线，要求启动很快 |
| `S06-H3` | 3 个交易日 | 3日内冲高 5%/8% | 短线接力 |
| `S06-H5` | 5 个交易日 | 5日内冲高 8% | 一周内机会 |
| `S06-H10` | 10 个交易日 | 10日内冲高 10%/12% | 中短线机会 |

不建议一开始只训练一个“万能短线模型”。不同周期的好票形态不同：

```text
2~3日模型更看重爆发和承接。
5日模型更看重启动后的持续性。
10日模型更接近当前22日模型，但资金周转更快。
```

## 标签设计

每个周期都用同一个标签框架：

```text
entry_price = D+1 open
future_high_h = max(D+1 ~ D+h high)
mfe_h = future_high_h / entry_price - 1
future_low_to_mfe_h = 入场后到最大冲高前的最低价
mdd_to_mfe_h = future_low_to_mfe_h / entry_price - 1
close_return_h = D+h close / entry_price - 1
days_to_mfe_h = 到达最大冲高的天数
```

训练目标不是单纯最大涨幅，而是短周期机会分：

```text
short_opportunity_score_h =
  mfe_h
  - 路径回撤惩罚
  - 高开惩罚
  - 不可买惩罚
  - 达标太慢惩罚
```

短周期要额外惩罚“慢”：

```text
2日模型：第2日才冲高也可以，但第1日最好。
3日模型：越早达标越好。
5日模型：第1~3日达标优于第5日达标。
10日模型：第1~5日达标优于第10日达标。
```

## 目标收益阈值

建议先跑下面的组合，不提前主观指定唯一答案：

| 窗口 | 目标阈值 |
|---:|---|
| 2日 | 3%、5%、8% |
| 3日 | 5%、8% |
| 5日 | 5%、8%、10% |
| 7日 | 8%、10%、12% |
| 10日 | 8%、10%、12%、15% |

核心评估不只看命中率，还要看：

```text
达标前最大回撤
未达标样本到期收益
未达标样本最大回撤
平均持仓天数
一个月账户收益
一个月最大回撤
资金利用率
交易次数
```

## 离场评估壳

短周期模型的离场仍先用简单规则，只为评估选股。

每个窗口先跑固定规则：

| 窗口 | 初始退出规则 |
|---:|---|
| 2日 | 5%止盈，否则第2日收盘；硬止损 -5%/-7% |
| 3日 | 5%或8%止盈，否则第3日收盘；硬止损 -6%/-8% |
| 5日 | 8%止盈，否则第5日收盘；硬止损 -8%/-10% |
| 7日 | 8%或10%止盈，否则第7日收盘；硬止损 -8%/-10% |
| 10日 | 10%或12%止盈，否则第10日收盘；硬止损 -10%/-12% |

这里的止损只是风险评估，不代表最终操盘。

最终操盘版应另训：

```text
盘中买点模型
持仓状态模型
动态卖点模型
```

## 月度账户评估

用户关心的是“一个月下来哪个方案收益最高”，所以短周期回测必须做账户级月度评估。

每个模型都输出：

```text
每月收益
每月最大回撤
每月交易次数
月内最大持仓数
平均资金利用率
胜率
平均单笔收益
中位单笔收益
最大单笔亏损
最大单笔盈利
连续亏损次数
```

验证期不能只看 2026-03-02 ~ 2026-04-07 一个窗口。

建议用滚动月评估：

```text
训练到 T 月以前，验证 T 月。
每次训练标签必须完整结束于验证月之前。
```

受当前数据量限制，能切的月份不多，但至少要做：

```text
2026-03 验证
2026-04 验证
2026-05 前半月观察，不作为完整月结论
```

如果历史标签不足，就先做“时间前推”而不是随机切分。

## TopK 设计

当前 22 日模型显示：

```text
Top1 明显优于 Top1+Top2。
Top2 会带入很多弱票。
```

短周期仍然先以 Top1 为主。

但可以补充评估：

| 模式 | 说明 |
|---|---|
| `top1_only` | 每天只买 Top1 |
| `top1_if_score_gap_ok` | Top1 分数低于阈值则空仓 |
| `top1_top2_conditional` | 只有 Top2 分数接近 Top1 且风险低时才买两只 |
| `cash_when_no_signal` | 没有高质量信号就空仓 |

短周期更需要允许空仓。每天硬买一只可能降低收益。

## 模型训练方案

第一阶段：多标签同源训练。

```text
一次构建 h=2/3/5/7/10 的全部标签。
每个周期独立训练一个排序模型。
所有模型共享同一套基础特征。
```

第二阶段：多目标比较。

```text
对每个周期模型，分别跑不同止盈/止损/到期组合。
按账户月收益、最大回撤、资金利用率排序。
```

第三阶段：组合路由。

如果多个周期各有优势，再训练一个路由器：

```text
当市场热、连板多、主线强：偏 H2/H3。
当市场中性、趋势延续：偏 H5/H7。
当市场弱但有结构性机会：偏 H10 或空仓。
```

## 第一轮优先级

第一轮不要做太复杂，建议按这个顺序：

```text

2. 训练 H3/H5/H10 三个模型。
3. 每个模型只跑 Top1。

```

## 判断标准

短周期模型只有在满足下面条件时，才值得进入前哨验证：

```text
Top1 月度账户收益为正。
最大回撤显著低于 22日模型。
交易次数足够多，不依赖1~2笔大票。
未达标样本亏损可控。
冻结模型后仍能持续给出有效信号。
```

如果短周期模型收益不如 22 日模型，也仍然有价值：

```text
它可以作为买点确认器。
它可以过滤 22 日模型里启动太慢的票。
它可以决定是否等回调再买，而不是次日开盘买。
```

## 当前假设

下一轮最值得验证的假设：

```text
H5/H7 可能比 H2/H3 更稳。
H2/H3 可能命中率更高，但容易被高开和洗盘影响。
H10 可能保留 22 日模型的大部分优势，同时提高资金周转。
短周期不能简单缩短 22 日标签，需要重新训练独立模型。
```

第一轮研究的最终排序标准：

```text
按月度账户收益排序。
收益相近时，优先最大回撤更小、交易分布更均匀、资金利用率更高的方案。
```

### H5 最佳方案交易特征

H5 最佳方案共 25 笔：

```text
胜率 60.00%
平均单笔净收益 +1.89%
中位单笔净收益 +7.46%
平均持仓 3.80 个交易日
账户收益 +40.60%
最大回撤 -10.45%
```

它的特征是：

```text
不设机械硬止损反而优于 -8% / -10% 止损版本。
短周期里固定止损会把很多后续反弹票提前打掉。
5日窗口比2/3日更能容纳强势票的洗盘和再冲高。
```

### 当前结论

下一步重点不是 2/3 日超短线，而是：

```text
优先继续优化 H5。
H7 作为备选。
H2/H3 暂不作为独立交易模型。
H10 的收益太弱，不如保留原 22 日机会模型。
```

H5 可以作为 22 日模型的补充：

```text
22日模型负责发现中短周期大机会。
H5 模型负责判断这只票是否有一周内启动潜力。
两个模型重合时，可以提高候选优先级。
22日模型强但H5弱时，可能需要等买点，不适合次日直接冲。
```
