# S06 机会发现模型当前版记录

## 定位

这一版模型的核心任务是选股，不是完整操盘。

它回答的问题是：

```text
D 日盘后，在全市场主板 10cm 股票里，选出 D+1 值得重点看的 Top1。
目标不是预测明天涨不涨，而是预测买入后未来 22 个交易日内有没有足够高的冲高机会。
```

当前模型里包含离场规则和一个轻量持仓模型，但它们的定位只是评估选股效果。

它们不是成熟操盘系统，原因是：

```text
离场规则很粗：15%止盈、12%硬止损、22日到期。
持仓模型样本很少，只是辅助判断是否提前退出。
没有使用5分钟级真实盘中路径训练精细卖点。
没有做盘口挂撤单的长样本训练。
没有经过冻结模型后的真实前推验证。
```

所以当前版可以称为：

```text
机会发现 / 选股候选生成器
```

不应称为：

```text
自动交易策略
```

## 训练目标

信号日为 `D`，入场日为 `D+1`。

核心标签：

```text
entry_price = D+1 open
max_runup_22d = max(D+1 ~ D+22 high) / entry_price - 1
mdd_to_mfe = 入场后到最大冲高前的最低价 / entry_price - 1
close_return_22d = D+22 close / entry_price - 1
```

模型不是直接训练“涨 15%/不涨 15%”二分类，而是训练一个机会分：

```text
opportunity_score =
  未来22日最大冲高
  - 冲高前路径回撤惩罚
  - D+1 高开过多惩罚
  - D+1 接近一字涨停不可买惩罚
```

这样做的目的：

```text
不只找涨幅最大，还要找尽量可买、路径不太差、冲高更可兑现的股票。
```

## 特征

第一版核心特征只使用长样本可覆盖字段：

```text
价格位置、近 N 日涨跌幅、波动率、均线偏离
L1/L2 主力和超大单净流入
主动买卖强度、L2 正净流入占比
既有 stealth / breakout / distribution 分数
热点主题 rank / score / lifecycle
全市场情绪和资金环境
```

没有纳入主模型的影子特征：

```text
order_imbalance_ratio
cvd_ratio
add_buy_ratio / add_sell_ratio
cancel_buy_ratio / cancel_sell_ratio
buy_support_ratio / sell_pressure_ratio
avg_book_imbalance_ratio / close_book_imbalance_ratio
thin_book_bar_count
```

这些字段未来可以单独做 `full_order_book` 版本。

## 真实交易评估口径

严格回测使用以下约束：

```text
训练标签完整结束于验证开始日前，避免未来22日标签跨进验证期。
D 日盘后出信号。
D+1 开盘买入。
A股 T+1，买入当天不能卖。
次日接近涨停/一字板不买。
次日高开超过 6.8% 不买。
次日低开超过 -5.5% 不买。
买入滑点 15bp。
卖出滑点 15bp。
双边费用合计 20bp。
账户回测按真实资金占用，不提前把未来收益滚入下一天。
买入按 100 股一手取整。
同一股票持仓期间不重复加仓。
```

## 验证结果

验证期：

```text
2026-03-02 ~ 2026-04-07
共 26 个信号日
```

严格训练切分：

```text
训练样本标签结束日 < 2026-03-02
训练信号日最后到 2026-01-21
验证信号日从 2026-03-02 开始
```

Top1 未来 22 日最大冲高分布：

| 区间 | 比例 |
|---|---:|
| < 5% | 11.54% |
| 5% ~ 10% | 19.23% |
| 10% ~ 15% | 3.85% |
| 15% ~ 20% | 7.69% |
| >= 20% | 57.69% |

核心结论：

```text
Top1 未来22日达到 15% 冲高的比例是 65.38%。
Top1 未来22日达到 20% 冲高的比例是 57.69%。
```

但未达到 15% 的样本并不温和：

```text
未达15%样本的22日收盘平均收益: -12.69%
未达15%样本的22日收盘中位收益: -11.20%
未达15%样本的平均最大回撤: -20.52%
```

所以不能使用：

```text
到15%卖；没到15%就死拿满22天。
```

## 简化离场评估

固定退出规则对比：

| 规则 | Top1 平均单笔净收益 | 胜率 | 备注 |
|---|---:|---:|---|
| 15%止盈，否则22日收盘卖 | +5.43% | 69.23% | 不止损，尾部风险大 |
| 15%止盈，8%止损，否则22日收盘卖 | +0.99% | 42.31% | 容易误杀洗盘票 |
| 12%止盈，8%止损，否则22日收盘卖 | +0.30% | 42.31% | 止盈过早，收益被压低 |

当前账户回测最佳组合：

```text
Top1 + 15%止盈 + 12%硬止损 + 持仓模型辅助退出
```

结果：

| 指标 | 数值 |
|---|---:|
| 实际成交 | 13 笔 |
| 账户收益 | +87.58% |
| 最大回撤 | -5.54% |
| 胜率 | 53.85% |
| 平均持仓 | 8.69 个交易日 |

这个结果只说明选股模型有明显候选价值，不说明离场模型已经成熟。

## 当前可用方式

可以作为研究版候选生成器：

```text
每天盘后生成 Top1 / TopN 候选。
次日开盘只在高开不超过 6.8%、不接近涨停时考虑买。
先用小仓位或模拟盘冻结验证。
```

不建议：

```text
不建议直接无脑重仓买。
不建议把当前简化离场规则当成熟操盘规则。
不建议因为 13 笔账户收益高就认为已投产。
```

当前投产等级：

```text
研究版有效
可以前哨验证
不够自动交易投产
```

## 后续用途

这个模型后续可以有三种用法：

```text
1. 继续优化为独立的中短周期机会发现模型。
2. 作为其它策略的候选池过滤器。
3. 与更精细的买点/卖点模型组合，选股和交易拆开训练。
```

更推荐第三种：保留这个模型的“发现高弹性票”的能力，把真正操盘交给单独的买点、持仓、离场模块。
