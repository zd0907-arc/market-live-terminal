# 2024-2025 试盘后大涨研究结论

## 结论

- 研究范围已经从短窗口扩到 `2024-09-02 ~ 2025-12-31`，共识别 `852` 次试盘，覆盖 `599` 只股票。
- 试盘后不是“普遍一路上涨”，而是“后面经常有一波冲高机会，但同样常见先跌、深跌、反复震荡”。
- 如果目标是找“最后会走一波大涨”的试盘，最有价值的不是追最暴力、最放量的单次异动，而是找 **强 OIB、但不过度极端、且处在第二次或第三次试盘附近** 的样本。
- 只基于试盘做盘后买入可以做原型，但还不够成熟，当前更像事件博弈策略，不像稳定的中线选股策略。

## 1. 大样本下，试盘后的真实路径

- 全部 `852` 次试盘里，`20` 日内冲到 `+15%` 的比例是 `36.7%`。
- `40` 日内冲到 `+20%` 的比例是 `39.7%`。
- `60` 日内冲到 `+30%` 的比例是 `34.6%`。

但另一面也要看：

- `20` 日内连试盘日收盘价都没重新站回去的，占 `7.4%`。
- `20` 日内出现明显深跌、而且连 `+5%` 反弹都没给过的，占 `14.1%`。
- `20` 日内先打出 `-8%` 再去冲 `+15%` 的情况，占 `52.0%`。

这说明：

- 试盘后走成大涨，并不等于后面马上平滑上涨。
- 更常见的是先给震荡、洗盘、回撤，再逐渐走出结果。

## 2. 第一次、第二次、第三次试盘，差别在哪里

### 第一次试盘

- 样本 `599` 次。
- `20` 日内冲到 `+15%` 的比例 `39.2%`。
- `40` 日内冲到 `+20%` 的比例 `42.2%`。
- `60` 日内冲到 `+30%` 的比例 `36.7%`。
- `20` 日内完全没回到试盘日收盘之上的，占 `6.7%`。

结论：

- 第一次试盘是最常见、也最像“资金开始摸票”的阶段。
- 它后面最容易出大波段，但并不等于第二天就舒服。

### 第二次试盘

- 样本 `162` 次。
- `20` 日内冲到 `+15%` 的比例 `31.5%`。
- `40` 日内冲到 `+20%` 的比例 `34.6%`。
- `60` 日内冲到 `+30%` 的比例 `30.3%`。
- `20` 日内完全没回来的，占 `8.0%`。

结论：

- 第二次试盘不是天然更强。
- 普通第二次试盘，短线体验往往比第一次更差，更像主力继续试，但筹码并不轻。

### 第三次试盘

- 样本 `61` 次。
- `20` 日内冲到 `+15%` 的比例 `27.9%`。
- `40` 日内冲到 `+20%` 的比例 `31.1%`。
- `60` 日内冲到 `+30%` 的比例 `26.2%`。
- `20` 日内完全没回来的，占 `11.5%`。

结论：

- 第三次试盘之后，普通样本并没有明显更好。
- 如果不加筛选，反而更像“反复折腾但不一定成”的状态。

## 3. 真正值得看的是“第二/第三次 + 强 OIB”

### 直接看第二次/第三次 + OIB 前 20%

- 样本 `41` 次。
- `20` 日内冲到 `+15%` 的比例 `41.5%`。
- `40` 日内冲到 `+20%` 的比例 `41.5%`。
- `60` 日内冲到 `+30%` 的比例 `26.8%`。
- `20` 日内完全没回来的比例 `0%`。
- `20` 日内深跌且没给过 `+5%` 机会的比例 `9.8%`。

这组比普通第二次/第三次试盘明显更健康，至少说明：

- 不是越多次越好；
- 而是到了第二次、第三次时，如果订单失衡仍然很强，说明主导资金还在主动试，而且没完全放弃。

### 再加一个“回吐适中”约束

规则：

- 第二次或第三次试盘
- `OIB` 落在全样本前 `20%`
- 同日回吐比例在 `0.35 ~ 0.80`

结果：

- 样本 `28` 次
- `20` 日内冲到 `+15%` 的比例 `42.9%`
- `40` 日内冲到 `+20%` 的比例 `39.3%`
- `60` 日内冲到 `+30%` 的比例 `32.1%`
- `20` 日内完全没回来的比例 `0%`
- `20` 日内深跌且没给过 `+5%` 的比例只有 `3.6%`
- 冲到 `+15%` 的中位等待时间约 `8` 天
- 冲到 `+20%` 的中位等待时间约 `7` 天

这是目前最像“盘后可以买、并且后续比较容易走出一波”的试盘子集。

## 4. 反向看失败样本，能发现什么

失败样本并不是“不够猛”，反而经常更极端。

对比 `20` 日内冲到 `+15%` 的大涨样本和 `20` 日内完全没回本的失败样本：

- 失败样本的日内拉升幅度更大。
- 失败样本的成交额放大倍数更高。
- 失败样本的向下跳空更重。
- 失败样本的试盘顺序更靠后一些。

一句话：

- **过于极端的试盘，不一定是强，很多时候是筹码结构更差。**

所以如果目标是找后面会走大涨的一波，不应简单追求：

- 拉得越猛越好
- 放量越大越好
- 跳空越深越好

这些特征在失败样本里一样很多。

## 5. 盘后买入原型，当前能走到哪一步

如果对全部试盘做最简单的盘后买入：

- 次日开盘买，持有 `5~10` 天，平均收益只有小幅正值；
- 中位数仍然偏负；
- 说明“全样本无脑买”不成立。

但对更干净的子集：

- 第二/第三次 + 强 OIB + 回吐适中

更适合做这种原型：

1. 盘后识别事件
2. 次日开盘或次日回踩承接后买入
3. 持有窗口控制在 `5~10` 个交易日
4. 风格偏事件博弈，不做长期死拿

当前更像一个可继续优化的策略原型，不是最终版。

## 6. 现阶段最像有效规则的描述

如果只用业务语言描述：

- 不是第一次突然拉一下就买
- 也不是反复试很多次就一定更强
- 更值得关注的是：
  - 已经试过一两次
  - 这次拉升时主动资金推进仍然很强
  - 当天虽然回吐，但没有夸张到完全被砸烂
  - 后面一到两周内，更容易走出真正的一波
