# 试盘后“首板 / 连板 / 强趋势”目标研究

## 结论

- 这里说的“首板候选池”和“趋势候选池”，不是硬规则买卖池，而是试盘后的两类概率池。
- 目标不是直接告诉你“买不买”，而是告诉你：
  - 这次试盘后，更像后面会出首板
  - 还是更像后面会走一波趋势

- 如果业务目标是“通过试盘，找后面会被真正拉起来的票”，那不能只看平均收益，要把目标拆成两类：
  - 会不会等来 **首板 / 连板**
  - 会不会走成 **20~40 日的强趋势**
- 这两类目标，对应的试盘口径不完全一样。
- 当前数据更支持这样理解：
  - **第一次试盘 + 强 OIB + 回吐适中**，更像“等首板”
  - **第二次/第三次试盘 + 强 OIB + 回吐适中**，更像“等一波趋势拉升”

## 1. 全部试盘里，真正被拉起来的比例有多高

样本范围：`2024-09-02 ~ 2025-12-31`

总样本：`852` 次试盘

后续结果：

- `10` 日内有过触板：`36.0%`
- `20` 日内有过触板：`49.1%`
- `10` 日内有过涨停收盘：`28.1%`
- `20` 日内有过涨停收盘：`39.6%`

如果继续看强度：

- 从第一次涨停收盘开始，后面还能走成 `2` 连板的：`12.3%`
- 能走成 `3` 连板的：`4.8%`
- `20` 日内最高涨幅达到 `+20%` 的：`27.1%`
- `40` 日内最高涨幅达到 `+30%` 的：`27.0%`

这说明：

- 试盘后等来“被拉”的概率并不低；
- 但真正走成连板强攻的，占比明显比“只是后来冲一波”低；
- 所以要先明确，你到底要的是“首板候选”，还是“趋势候选”。

## 2. 第一次试盘，更像首板候选池

全部第一次试盘：

- `20` 日内涨停收盘：`40.6%`
- `2` 连板：`13.2%`
- `3` 连板：`5.3%`
- `20` 日内最高涨幅 `+20%`：`28.6%`
- `40` 日内最高涨幅 `+30%`：`29.2%`

如果只看：

- 第一次试盘
- `OIB` 前 `20%`
- 回吐比例在 `0.35 ~ 0.80`

结果会更干净：

- 样本 `75`
- `20` 日内涨停收盘：`46.7%`
- `2` 连板：`17.3%`
- `3` 连板：`5.3%`
- `20` 日内最高涨幅 `+20%`：`33.3%`
- `40` 日内最高涨幅 `+30%`：`29.3%`
- 首次触板出现的中位等待时间：`7.5` 天
- 首次涨停收盘出现的中位等待时间：`8.5` 天

业务解释：

- 第一次试盘之后，如果主导资金推进很强，而且当天虽然回吐但没有被砸烂，更像是在确认筹码结构。
- 这类票更容易在后面一到两周内等到一次正式点火，尤其像“首板前的摸票”。

## 3. 第二次 / 第三次试盘，更像趋势候选池

全部第二次和第三次试盘合并看：

- `20` 日内涨停收盘：`37.2%`
- `2` 连板：`10.8%`
- `3` 连板：`3.6%`
- `20` 日内最高涨幅 `+20%`：`25.1%`
- `40` 日内最高涨幅 `+30%`：`21.5%`

如果只看：

- 第二次或第三次试盘
- `OIB` 前 `20%`
- 回吐比例在 `0.35 ~ 0.80`

结果是：

- 样本 `28`
- `20` 日内涨停收盘：`32.1%`
- `2` 连板：`17.9%`
- `3` 连板：`10.7%`
- `20` 日内最高涨幅 `+20%`：`39.3%`
- `40` 日内最高涨幅 `+30%`：`28.6%`
- 首次触板中位等待时间：`14` 天
- 首次涨停收盘中位等待时间：`15` 天

业务解释：

- 这类票不一定马上给你首板，等待时间更长；
- 但一旦走成，往往不是一日脉冲，而更像一波趋势启动，甚至有更高的 `3` 连板概率。

## 4. 为什么“第二三次 + 强 OIB”不像首板，却像趋势

因为这类票更像：

- 资金已经试过，不是第一次摸
- 但现在订单失衡还强，说明并没有完全放弃
- 当天回吐适中，说明不是硬拉失败，也不是纯脉冲出货

所以它不像“明天就点火”的那种首板前兆，
更像“已经盯上了，后面等窗口、等消息、等情绪，再拉一波”。

这和你的业务直觉是一致的：

- 试盘不一定马上拉
- 也可能先砸、先洗、先等预期兑现
- 真正关键是：主导资金有没有继续留在里面、有没有继续试

## 5. 当前最像有效的两条线

### 线 1：首板预期线

更适合找：

- 第一次试盘
- `OIB` 很强
- 当天回吐适中

目标：

- 找后面 `7~10` 天内容易出首板的票

### 线 2：趋势预期线

更适合找：

- 第二次或第三次试盘
- `OIB` 很强
- 当天回吐适中

目标：

- 找后面 `10~20` 天内可能走出一波 `+20%` 以上趋势的票
- 不要求立刻首板，但要求后面有明显被拉升的空间

## 6. 当前不该怎么想

- 不要把所有试盘都当成“明天买了等首板”
- 不要把“拉得最猛、放量最大”的样本直接当成最好样本
- 不要把第二次第三次试盘简单理解成“比第一次更强”

更合理的思路是：

- 第一次强试盘：偏首板候选
- 第二三次强试盘：偏趋势候选
- 极端放量、极端大跳空、极端猛拉：要警惕是失败试盘或筹码结构太差
