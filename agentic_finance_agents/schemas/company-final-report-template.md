# 单公司最终报告模板

## 目标

单公司研究的最终输出首先要让用户一眼看懂：

1. 这家公司是做什么的。
2. 收入从哪里来。
3. 利润主要由什么贡献。
4. 财务上有什么基本特征。
5. 股价过去主要跟什么变量走。
6. 当前估值按不同利润分母怎么看。
7. 接下来应该盯哪些外部变量和公司变量。

这份模板优先服务 A 股研究场景，不写目标价、买卖建议或自动交易指令。

## 最终报告固定结构

```markdown
# <公司名> <代码> 单公司研究

## 一句话结论
用 2-4 句话说明：公司本质、当前主要矛盾、股价驱动、研究状态。

## 1. 公司是做什么的
- 主营业务：
- 产业链位置：
- 客户/渠道：
- 经营模式：
- 业务关键词：

## 2. 收入从哪里来
用表格拆收入结构，优先按产品、地区、渠道三层。

| 维度 | 项目 | 收入 | 占比 | 同比 | 毛利率 | 判断 |
|---|---|---:|---:|---:|---:|---|

结论要回答：收入主要靠哪个业务、哪个地区、哪个渠道。

如公司是复合业务、资源、化工、材料链或项目型公司，必须补充业务层级关系：

- 分行业、分产品、分地区、销售模式分别是什么口径。
- 哪些产品是行业子项，不能重复加总。
- 哪些毛利率是行业整体口径，不能冒充单品毛利率。
- 哪些业务是已兑现收入，哪些只是项目储备或中期 option。

## 3. 利润主要来自什么
不是只列净利润，而要拆利润来源：

- 哪些产品贡献毛利。
- 哪些地区或渠道毛利率更高。
- 费用、财务费用、减值、非经常损益对利润的影响。
- 本期利润是经营驱动，还是一次性项目/金融项目/汇兑/资产处置驱动。

## 4. 财务基本盘
用业务语言说明：

- 增长：收入和扣非利润趋势。
- 质量：现金流、应收、存货、减值、商誉。
- 杠杆：有息负债、资产负债率、财务费用。
- 分红和资本开支。

## 5. 估值分母和同业位置
不能只引用软件显示的当前 PE。必须拆清楚估值分母：

| 估值口径 | 分母 | PE/倍数 | 适用性 | 判断 |
|---|---:|---:|---|---|
| 上一完整年度 | 归母/扣非净利 |  | 已兑现利润 | 高/合理/低/无法判断 |
| TTM | 最近四季利润 |  | 连续经营口径 | 高/合理/低/无法判断 |
| 最新季度年化 | 最新单季扣非净利 x 4 |  | 压力测试/市场误用锚 | 高/合理/低/无法判断 |
| 情景利润 | Bear/Base/Bull |  | 模型假设 | 高/合理/低/无法判断 |

必须回答：

- 利润分母相对上一年发生了什么变化。
- 最新季度年化是不是可持续，为什么。
- 同业或行业中位数、区间、分位如何；无法取得时写缺口。
- 估值变便宜是因为经营改善，还是因为使用了不可持续的季度高利润。

## 6. 股价过去跟什么走
这是 A 股研究必须输出的部分。

| 驱动因子 | 证据 | 可信度 | 怎么跟踪 |
|---|---|---|---|
| 主题/行业热度 | 例如板块热度、概念映射、同业共振 | high/medium/low | 盯哪个板块/主题 |
| 业绩/财报兑现 | 财报日前后走势、扣非/CFO 等 | high/medium/low | 盯哪些财务指标 |
| 商品/地缘/宏观变量 | 产品价格、汇率、战争、能源、政策 | high/medium/low | 盯哪个外部变量 |
| 资金/风格 | 小盘、融资、L2、游资、量价结构 | high/medium/low | 盯成交量、资金、风格 |
| 公司事件 | 并购、减持、分红、问询、订单、政策 | high/medium/low | 盯公告和事件 |

必须给出一句“最像什么类型的股票”：

- 商品价格型：股价跟产品价格或原料价格走。
- 地缘事件型：股价跟战争、制裁、航运、能源安全等事件走。
- 政策催化型：股价跟政策、补贴、集采、监管边际变化走。
- 主题资金型：股价跟概念热度、板块轮动、小盘风格走。
- 业绩兑现型：股价跟订单、收入、利润、现金流兑现走。
- 资产/分红型：股价跟估值、分红、回购、现金资产走。
- 混合型：没有单一主变量，需要分阶段跟踪。

对商品、资源、化工、农业、能源、航运等公司，必须额外给出变量传导关系：

| 变量 | 与公司关系 | 传导路径 | 归因等级 |
|---|---|---|---|
| 直接产品价格 | 直接产品/主要收入项 | 价格 -> 收入/毛利/库存 | high/medium/low |
| 间接商品价格 | 原料/替代变量/交易情绪 | 成本曲线/替代价值/市场叙事 -> 公司产品价格或估值 | high/medium/low |
| 项目或概念 | 中期 option/主题资金 | 公告节点/客户验证/产能爬坡 -> 未来利润或估值弹性 | high/medium/low |

禁止把间接变量写成直接收入项。公司不生产某商品时，只能写清传导链，不能写成该商品涨价直接贡献收入。

## 7. 现在最应该盯什么
列 5-8 个监控变量，必须具体。

| 变量 | 为什么重要 | 触发什么判断 |
|---|---|---|

## 8. 反证和风险
列出能推翻当前研究判断的证据。

对尚未兑现的项目，必须单独列出：

| 项目 | 当前状态 | 还缺什么 | 是否进入当前利润判断 |
|---|---|---|---|
| 项目/产品 | 已公告/建设中/试车/客户验证/已投产 | 注册、资金、环评、试车、订单、毛利、现金回款 | 是/否 |

## 9. Agent 来源
说明每个关键判断来自哪个 Agent。

## 10. 数据缺口
列出没查到、不能确认、不能沉淀的数据。
```

## Agent 分工

| 内容 | 主责 Agent | 说明 |
|---|---|---|
| 公司做什么、收入构成、利润来源 | `03 财报与管理层信号 Agent` | 从年报、季报、公告抽取产品/地区/渠道、毛利率、利润影响因素 |
| 财务质量 | `09 财务质量审查 Agent` | 抽象成增长、质量、杠杆、现金流、分红、资本开支 |
| 行业和外部变量 | `05 市场与行业研究 Agent` | 找到产品价格、政策、地缘、行业景气、同业、主题热度等外部驱动 |
| 股价过去跟什么走 | `06 估值与股价驱动核查 Agent` | 结合价格、事件、板块、同业、L2 和外部变量做归因 |
| 估值分母和同业位置 | `06 估值与股价驱动核查 Agent` | 比较年度、TTM、最新季度年化和同业/行业估值位置 |
| 事实边界 | `07 事实一致性对账 Agent` | 检查驱动归因是否过度推断 |
| 最终表达 | `01 研究总签 Agent` | 用用户能看懂的结构输出 |

## 股价驱动归因要求

股价驱动不能只凭感觉，必须至少比较以下证据：

1. 标的股价的 20/60/120 日区间走势。
2. 同期行业板块、主题或核心同业走势。
3. 同期公司公告、财报、问询、分红、并购、减持、异常波动等事件。
4. 如公司和商品/地缘/汇率/航运/能源有关，要列出对应外部变量。
5. 如是主题股，要说明主题热度是否连续，而不是只看单日涨停。
6. 如 L2 或资金口径冲突，只能写“资金信号不稳定”，不能写确定性流入/流出。

输出结论必须带置信度：

- `high`：价格、同业/主题、事件三者同向，且多次重复。
- `medium`：有一定同步，但样本少或存在其他解释。
- `low`：只是可能相关，不能作为主要跟踪变量。

## 商品价格证据要求

如果公司利润或股价可能跟商品价格、资源品、农产品、能源、汇率、地缘事件相关，最终报告前必须建立商品价格证据表：

| 字段 | 要求 |
|---|---|
| 商品名称 | 区分直接产品、原料、替代变量、下游需求变量和交易主题 |
| 与公司关系 | 直接收入项、成本项、替代变量、下游需求、主题情绪 |
| 频率 | 日度、周度、月度、公告口径或新闻口径 |
| 覆盖区间 | 至少覆盖股价归因的 20/60/120 日窗口 |
| 数据源 | 本地库、公司公告、免费公开源或人工补证 |
| 可用等级 | high/medium/low，并说明不能用的原因 |

没有连续价格序列时，只能写方向性判断和数据缺口，不能做强相关或高置信归因。

## 结构化证据 Ledger

Markdown 报告可以作为研究产物，但字段要晋级到正式页面或数据库前，必须补结构化证据 ledger。每个可晋级字段至少需要：

| 字段 | 说明 |
|---|---|
| `fact_id` | 稳定事实 ID |
| `field_name` | 对应候选字段 |
| `value` | 可入库值 |
| `source_type` | 年报、季报、公告、问答、行情、本地数据库、商品源 |
| `source_url_or_path` | 原始来源 |
| `source_date` | 来源发布日期或数据日期 |
| `page_or_table` | PDF 页码、表名、字段路径 |
| `agent_used_by` | 哪些 Agent 使用 |
| `confidence` | high/medium/low |
| `promotion_status` | ready/needs_review/blocked |

没有 ledger 的字段最多只能是候选，不应进入正式库。
